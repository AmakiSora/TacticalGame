## 为什么是"第五种完全不同的算法"

同时模式已有四条路线，各自占住一个极值：

- `random-sim`：动作级**无模型**随机（性能下界）；
- `dest-prob`：**落点概率模型**——预测敌方单位会落在哪些格，再按期望值贪心；
- `kriegspiel`：**整份计划联合搜索**——分步 rollout 评估计划组合 + 风险规避；
- `matrix-eq`：**正则形式博弈**——计划组合矩阵 + CFR 求均衡混合。

它们共同的隐含假设是"这一轮怎么下最好"。tempo 换的问题是**"这一轮的每一拍分别该发生什么"**：
结算按行动点逐拍推进，早拍击杀会作废受害者后续全部动作，晚拍占点同样算分却少挨一整轮打。
拍序本身就是一种资源，前四条路线都没有把它当作一等公民来优化。tempo 的做法是：

1. 用敌方的**离散剧本**（不是概率格）投影出每一拍谁在哪；
2. 把这些投影叠成「第 k 拍 × 格子」的**威胁时间线**，给每个移动候选算"落地后还要挨几拍"；
3. 用 `adjudication` 快照的**分差 + 剩余轮数**决定这一轮是收着打还是 all-in；
4. 最后按价值把动作**排进具体的拍**：斩杀抢早、占点压尾、治疗跟在预测伤害之后。

## 算法原理

### 1. 敌方剧本预测（level-1）

对每个敌军单位，按"抢点 > 原地开火 > 残血撤退 > 推进"的通用优先级推一条最可能的行为，
输出 `posAt(k)` 与开火拍（原地开火第 1 拍、推进后开火第 2 拍）。剧本是**通明的启发式**，
不记忆对手历史、不针对任何具体算法或地图。

### 2. 威胁时间线

```
threat[k][cell] = Σ 预测射击(0.65 × 期望伤害) + 可及火力区(0.08 × 期望伤害)
```

攻击在同一拍内于移动之后结算，所以第 1 拍的威胁就按敌方投影位置计。
移动候选的暴露成本 = 落地拍起各拍威胁之和 × 单位每点 HP 价值 × 姿态系数。

### 3. 裁决姿态

读 `game.adjudication`（`weights` / `scores` / `maxTurns`）：

- `rel = (我 - 最强对手) / 归一化分母`；
- 攻击价值 × `aggression = clamp(1 - 1.5·rel)`，暴露成本 × `riskAversion = clamp(1 + 1.5·rel)`；
- 剩 ≤2 轮时推到极值：领先 0.6/1.8（保分），落后 1.6/0.6（搏命）；
- 补给权重为 0 的地图上，末轮把补给全部换成单位。

### 4. 候选与排程

候选 mission 四类：攻击（原地 / 移动后，含锁定与预测射击）、占点、治疗、部署，
外加避险/推进兜底走位。价值 = 期望伤害 × 目标每点 HP 价值 + 击杀奖金 + 据点收益，
命中概率：HQ 1.0、锁定 0.95、剧本落点 0.7、纯预测 0.55、不动的目标 0.6、会动的目标 0.22。

排程按价值贪心插入：`early` 插在已有 early 之后、`mid` 居中、`late` 压尾；
两腿 mission（移动→攻击/治疗）整对插入，先移后打；移动腿额外扣 0.3 价值（同值时少动腿优先，
降低失败连锁风险）。容量不足时整条跳过——瞄准格是按投影位置校验的，不能砍掉移动腿降级。

### 5. 接口适配与容错

- 每次 `decide` 都从**已入队前缀**（`plan.myQueue`）的投影重排剩余计划，前缀永远不被改写；
- 模块级记忆记录"某个队列长度上给过的动作"，队列没增长即判定被拒，重排时禁掉该动作；
- 全部数值读 `config` / `adjudication`，无 `mapId` 分支；炮火区仅在 `game.artillery` 存在时过滤。

## 验证（冒烟，无服务器）

`tests/algorithms/tempo.test.ts`（10 例）：

- 计划约束：无座位 / 已提交 / AP 用尽均返回 `null`；
- 锁定射击瞄敌人当前格；移动后攻击按投影位置取瞄准格；支援治疗受伤友军；侦察兵抢可达据点；
- 被拒动作记忆：同轮同队列长度再次询问会给出不同动作；
- 真实 `standoff`：双方整轮计划逐条通过引擎入队校验并正常结算；连续 5 轮零非法。

## 强度结论

**暂无同口径对照。** 未跑镜像裁判与真实引擎跑批，不与 `dest-prob` / `kriegspiel` / `matrix-eq`
做跨 harness 数字比较；补测计划：standoff + molten-throne × 上述三对手 × 30 局/图、同种子交替先手。

## 已知限制

- **单层剧本**：敌方只会按一条最可能剧本投影；面对随机化程度高的对手（如 `random-sim`）预测命中的期望会被高估或低估；
- **贪心排程**：不回溯，两腿 mission 放不下会被整条丢弃，某些轮次可能少打一发；
- **不做联合计划搜索**：不比较"我这轮 5 拍"的全组合（那是 kriegspiel / matrix-eq 的地盘），因此上限受候选粒度限制；
- **多人局**（standoff 3/6 人）只按全体敌人各自最优剧本叠加威胁，未建模敌人之间的互相牵制。

## 一句话总结

把"这一轮怎么下"拆成"每一拍该发生什么"：先预测敌人每拍在哪，再让自己的斩杀落在前拍、占点落在末拍。
