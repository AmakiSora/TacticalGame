# 普通观战页与玩家页棋盘动效设计

## 背景与范围

为普通观战页和玩家页补充棋盘事件动效，覆盖桌面与移动端：

- `public/spectator.html`
- `public/spectator-m.html`
- `public/play.html`
- `public/play-m.html`

`public/spectator2.html` 已有完整的动画实现，本次不修改，也不让普通页面依赖其私有代码。

动效只改变视觉反馈，不改变规则状态、事件协议、回放数据或交互判定。

## 方案

新增 `public/board-animation.js`，通过全局工厂暴露共享 Canvas 动画层。页面脚本继续负责地形、单位图标、生命条、选择高亮和触摸/鼠标交互；动画层负责时间状态与特效绘制。

动画层的核心状态：

- `unitViews`: 每个单位的当前坐标、目标坐标、透明度和出生时间。单位移动通过缓动插值，部署通过淡入缩放，死亡通过淡出处理。
- `effects`: 带 `start`、`duration` 和类型参数的短时效果队列。每帧更新并清理过期效果。

建议接口保持小而明确：

- `syncState(state, { animate })`: 根据当前规则状态建立或更新单位目标；首次加载、重建回放和手动刷新使用 `animate: false`。
- `recordEvent(event, state)`: 根据事件类型将视觉效果加入队列；实时 SSE 和回放逐步前进时调用。
- `update(now)`: 更新单位插值和过期效果。
- `drawEffects(ctx, now)`: 在页面完成基础棋盘绘制后绘制特效。
- `forEachUnit(callback)`: 将当前插值坐标、透明度和出生缩放交给页面的 `drawUnitMarker`。
- `reset()`: 切换对局或重建历史状态时清空动画状态。

页面在共享脚本之后加载各自脚本，并启动 `requestAnimationFrame` 循环。每一帧按“清屏/地形/高亮/据点与总部/动画单位/特效”的顺序绘制。无动画时循环只做轻量重绘，保证悬停和移动端拖拽仍然使用现有坐标换算。

## 事件与视觉反馈

颜色沿用现有普通页面和 `spectator2.html` 的语义：移动蓝、攻击红、治疗绿、部署金、拆除橙、占点使用阵营色。

| 事件 | 反馈 | 目标时长 |
| --- | --- | --- |
| `move` | 单位滑向目标格，目标格蓝色落点环 | 260ms / 400ms |
| `attack` | 攻击者与目标之间红色束线，目标红色受击环和轻闪 | 220ms / 360ms |
| `heal`, `control_point_repair` | 目标绿色扩散环，生命条随状态重绘 | 450ms |
| `deploy` | 单位从低透明度和小尺寸淡入，落点金色脉冲 | 500ms |
| `unit_death` | 单位淡出并产生橙红爆裂 | 500ms |
| `headquarters_destroyed` | 总部淡出、较大红色爆裂和环 | 700ms |
| `control_point_captured` | 据点使用新阵营色扩散脉冲 | 600ms |
| `control_point_neutralized` | 据点使用中立金色脉冲 | 500ms |
| `demolish` | 地块位置橙色爆裂 | 550ms |

事件队列设置有限上限，快速 SSE 或回放不会无限堆积。缺失单位、旧格式字段和异常坐标只跳过对应视觉效果，不能阻塞 `applyEvent`。

当 `prefers-reduced-motion: reduce` 生效时，插值和特效时长压缩到接近瞬时，但仍保留颜色、生命值和单位存在性变化。

## 页面接入

### 桌面观战页

- `app.js` 的 `stepForward()` 在应用事件后记录事件并同步动画目标。
- `rebuildToStep()` 重建状态后调用 `reset()` 与非动画同步。
- 切换对局和完整刷新清空动画；实时 SSE 逐事件播放。

### 桌面玩家页、移动玩家页、移动观战页

- 各自 `applyEvent` 保持规则逻辑不变。
- SSE 收到新事件后，先应用事件，再记录事件并以动画模式同步。
- `loadFullState()` 和手动刷新以非动画模式同步。
- 移动页面沿用当前缩放、平移和触摸手势，动画层每帧重新调用页面的 `hexToPixel` 结果，不保存屏幕坐标。

共享动画循环在页面断开或卸载时停止，避免重复 `requestAnimationFrame`。

## 验证标准

1. 四个普通页面均能加载共享脚本，既有 Canvas 绘制、交互和 SSE 不回归。
2. 移动、攻击、治疗、部署、死亡、总部摧毁、占点和拆除事件均能触发对应视觉反馈。
3. 回放逐步前进播放效果；首次加载、刷新和拖动时间轴不误播历史事件。
4. 单位插值、攻击束线和落点效果在桌面缩放、移动端缩放/平移后仍与棋盘格对齐。
5. 连续事件、缺失目标、旧事件字段和 `prefers-reduced-motion` 下无脚本异常。
6. 运行现有 `npm test`，并补充面向共享动画层的纯逻辑测试或页面静态检查。

## 不在范围内

- 不修改 `public/spectator2.html`。
- 不修改服务端事件结构、游戏规则或回放格式。
- 不引入新的图片资源、第三方动画库或 DOM 覆盖层。
