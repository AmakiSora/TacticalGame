# TacticalGame 3.2.1 版本升级设计

## 目标与版本边界

将仓库的当前应用版本从 `3.2.0` 统一升级到 `3.2.1`，并基于 `release/3.2.0` 的版本基线提交 `a394734` 与当前 `release/3.2.1` 的差异编写迭代说明。

历史发布章节、历史回放中的应用版本与 `schemaVersion`、旧设计文档示例以及依赖包自身版本不改写。`RELEASE_NOTES.md` 中现有的 `3.2.0` 及更早内容原样保留。

## 当前版本来源

以下位置表示当前应用版本，需要同步到 `3.2.1`：

- `package.json` 的根 `version`。
- `package-lock.json` 顶层及根包的 `version`。
- `public/version.js` 的 `window.APP_VERSION`。
- `README.md` 的当前版本说明。
- `skill/SKILL.md` 的应用版本说明。
- `tests/skill/ai-player.test.ts` 中对应的文档契约断言。

版本一致性测试读取上述主要来源，断言它们均为 `3.2.1`，避免以后只更新其中一部分。

## 3.2.1 迭代说明

`RELEASE_NOTES.md` 在 `3.2.0` 之前新增 `3.2.1` 章节，按用户功能归类，不按内部提交或文件逐条罗列。

### 娱乐数据看板重设计

- 将娱乐数据页从传统面板堆叠重构为战报式阅读结构。
- 重组战场脉搏、名场面、战术观察、兵种选择、模型战术档案和纪录柜等内容。
- 改进模型切换、动作构成、纪录分类、加载状态及响应式布局，继续使用现有 `fun-stats.json` 数据来源。

### 普通棋盘事件动效

- 为桌面与移动端玩家页、普通观战页增加共享 Canvas 动画层。
- 覆盖单位移动、攻击、治疗、部署、死亡、总部摧毁、据点占领/中立化和地块拆除反馈。
- 初次加载、刷新、切换对局和回放跳转直接同步状态；实时 SSE 与逐步回放播放动画。
- 支持生命值插值、实体淡入淡出、减少动态效果偏好和空闲停止持续重绘。
- `spectator2.html` 已有独立完整动画，不接入共享层，也不修改。

### 质量保障

- 新增共享动画层的运行时与页面接入测试，覆盖桌面、移动端和 `spectator2.html` 排除项。
- 完整 TypeScript 构建和 Vitest 测试套件作为发布验证门槛。

## 实施顺序

1. 先增加版本一致性测试，并在仍为 `3.2.0` 时确认测试按预期失败。
2. 更新所有当前应用版本来源和现有 Skill 文档断言。
3. 在 `RELEASE_NOTES.md` 顶部写入按上述结构整理的 `3.2.1` 说明，同时保留用户现有修改。
4. 运行聚焦测试、全量测试、构建、版本号搜索和 `git diff --check`。

## 验证标准

1. 当前应用版本来源全部显示 `3.2.1`。
2. 排除历史资料后，不再存在代表当前应用版本的 `3.2.0`。
3. `RELEASE_NOTES.md` 的 `3.2.1` 内容与 `a394734..HEAD` 的实际功能差异一致。
4. `3.2.0` 及更早发布说明、历史回放、Schema 和依赖版本未被批量改写。
5. 聚焦版本测试、完整测试套件和 TypeScript 构建均通过。
