## 核心教训

### 致命错误: 把主战场开在东北对 `player_b`，放任 `player_c` 锁死西/南三角据点

本局裁决权重 `controlPoint=75`，每个据点相当于75分，几乎等于一整支小部队。`player_c` 作为先手（`turnOrder` 第1）在第1轮就用侦察兵吃下 `cp_sw(-3,3)`，第2轮再拿 `cp_w(-3,0)`，第3轮补 `cp_se(0,3)`，此后长期维持 **3–4 据点**（`cp_w/cp_sw/cp_se` + 频繁的 `cp_center`）。

我方正确完成了东线开局：第1轮侦察兵(7,1)→(3,0)占 `cp_e`（supply +8），第2轮再占 `cp_ne(3,-3)`（forward_base +4 且部署折扣4）。但第3轮起主攻方向转向 `player_b` 的中心/北翼（打 `9a681c58` 侦察兵、`14c3f5f6` 游骑兵、后来的 `3323a01b`/`bb73559c`），而不是打断 `player_c` 的西线经济链。

**分数账面后果：**
- 终局据点：C×4 vs A×2 vs B×1 → 仅据点项就 300 vs 150 vs 75
- 我方累计收入约 252 补给（含初始后的 `income` 合计），C 约 306；C 每轮常有 base6+ctrl16~18
- 三方 **全员 HQ 伤害均为 0**，裁决完全由据点+军力决定；在这种权重下，与 B 互砍军力几乎无法追回 C 的 2 个据点差（150分）

**正确做法:** 东线两据点到手后，第3–5轮应集中步兵/侦察兵压 `cp_center` 并威胁 `cp_se`/`cp_w`，逼 C 从西线回防；对 B 只保持最小接触，必要时让 B 与 C 互耗，而不是自己当 B 的主坦。

## 经验教训

### ✅ 做得好的
1. **开局东线标准抢点:** 第1轮占 `cp_e(3,0)`、第2轮占 `cp_ne(3,-3)`，路径与距离正确，形成 supply+forward_base 基础盘（多数整轮收入18=6+8+4）
2. **中心争夺主动性:** 第6/10轮两次从 C 手中夺走 `cp_center`，并触发 `control_point_repair`（+8HP），说明读到了 repair 站价值
3. **NE 折扣部署:** 第9/11/13/15轮多次从 `cp_ne` 部署，单次节省4补给，累计折扣16；这是正确用 forward_base 的方式
4. **局部击杀效率:** 累计对单位造成约752伤害；确认击杀 B×4（2侦察+1步兵+1游骑）、C×3（2侦察+1步兵），说明近战集火执行不差

### ❌ 致命失误
1. **主威胁识别错误（第3轮起）:** 把火力优先打在 B 的中心/北翼单位上，而 C 已锁 `cp_w/sw/se`。在 `controlPoint=75` 的地图上，应优先“拆 C 的点”而不是“刷 B 的人头”
2. **中心有夺无守（第7–12轮）:** 中心三易其手，两次丢点都因单薄步兵被 C 多单位集火（`4d508b2b` 被 C 步兵+侦察连殴；`4a259c86` 被三单位收掉）。夺点后应同回合再塞1个可占点单位或后撤到可互相掩护格，而不是把残血步兵单独留在(0,0)
3. **从未攻击任何 HQ:** 三方 HQ 伤均为0。终局已不可能靠据点翻盘时，第13–15轮仍未派侦察向 C 的 HQ(-8,8) 或 B 的 HQ(0,-8) 做哪怕 1 点伤害；权重×5 下这是明确的终局漏分
4. **对 B 过度歼灭:** 击杀 B 的游骑/步兵提升了相对 B 的名次（最终第2而非第3），但对击败 C 几乎无贡献；这是“赢了支线、输了主线”

### 🔑 核心教训
> **“六方环线三人局：先手 C 若锁西/南三角，东线两据点只是保底；中盘每一行动点都必须服务于‘抢/守第3据点（优先中心）或拆 C 的点’，与侧翼玩家互砍人头不能当主战略。”**
