## 核心胜利策略

### 1. 双CP经济开局 + 提前爆破墙

**关键决策:** 第1轮同时抢占 `cp_nw` (+20收入) + 双重装并行推进到墙前，第2轮立即爆破2格墙洞。

```text
第1轮 / player_b: 侦察兵(-6,0)→(-4,-3) cp_nw；重装2路并进(-4,1)与(-3,-1)
第2轮 / player_b: 侦察兵→(-3,0) cp_w；重装(-4,1)→(-2,1) 爆破(-1,1)；重装(-3,-1)→(-1,-3) 爆破(0,-3)
第3轮 / player_b: 重装(-2,1)→(-1,2) 爆破(0,2)；重装(-1,-3)→(0,-3) 爆破(0,-2)
```

**为什么有效:**
- 第2轮结束已拥有 cp_nw(+20) + cp_w(+8) = 28 收入（基础10外加），经济领先
- 第3轮结束墙洞多达4格（(-1,1)/(0,-3)/(0,2)/(0,-2)），突破时间比对手早1轮
- 双向爆破形成钳形攻势，对手无法集中防御
- 重装移动3格/回合 + 爆破1格 = 每回合1爆破效率，最大化推进节奏

### 2. 优先击杀敌方突破侦察兵，压制信息战

**关键决策:** 第4-5轮连续攻击敌方通过爆破墙洞突入(1,1)的侦察兵，最终击杀。

```text
第4轮 / player_b: 重装(-1,2)→(1,2) 攻击侦察兵(1,1) 35伤害 65→30
第5轮 / player_b: 重装(1,2)→(2,2) 攻击侦察兵(3,2) 38伤害 30→0 击杀！
```

**为什么有效:**
- 敌方侦察兵是我方重装前出到(1,2)时的最大威胁——可侦查我方部署并偷取CP
- 侦察兵65 HP仅需2次重装攻击(35+38)即可击杀，性价比高
- 击杀后敌方失去我方阵地的"眼睛"，无法及时响应我方推进
- 第5轮击杀创造窗口期，让我方可在不被侦查的情况下推进重装

### 3. 重装濒死时果断撤退 + 抢第三据点

**关键决策:** 第6轮我重装2被敌方3个单位集火至21 HP，第7轮立即撤退(2,-2)→(1,-3)到安全位置，同时抢占`cp_sw`。

```text
第6轮 / player_a: 敌方重装+步兵+游侠集火我重装2：28+18+29=75伤害，96→21 HP
第7轮 / player_b: 重装(2,-2)→(1,-3)撤退；新侦察兵(-4,2)→(-4,3) cp_sw
```

**为什么有效:**
- 重装2若继续在(2,-2)战斗，下回合必死无疑
- 撤退到(1,-3)（墙后安全位置）保住了重装2的剩余价值
- 但第7轮敌方游侠仍攻击到(1,-3)击杀重装2——撤退稍微晚了一步，但保留了第6轮抢来的喘息空间
- 同步抢占`cp_sw`(+8收入+部署折扣)弥补了重装2阵亡的损失
- 第7轮结束：3据点 vs 敌方2据点，经济优势巩固

### 4. 战略转折：重装1独自突击敌方HQ

**关键决策:** 第8轮敌方部署游侠+第三个重装准备反扑时，我方重装1果断脱离战斗，单独推进到(5,2)，第9轮直冲(7,1)攻击敌方HQ。

```text
第8轮 / player_b: 重装(2,2)→(5,2) 推进（不参与集火）
第9轮 / player_b: 重装(5,2)→(7,1) 攻击敌方HQ(8,0) 42伤害
```

**为什么有效:**
- 击杀敌方剩余残血单位收益递减，而直接攻击敌方HQ是胜利捷径
- 敌方(8,0) HQ与(8,1)相邻，(7,1)→(8,0)恰好距离1可攻击
- 路径(2,2)→(5,2)→(7,1)仅需2轮抵达（避开敌方重装集中的(2,±1)/(3,-3)）
- 100 HP敌方HQ仅需3次重装攻击即可摧毁（实际42+37+41=120伤害，3轮完成）

### 5. 后期利用收入差扩大优势

**关键决策:** 第7轮抢占`cp_sw`后我方收入+8（总+36/回合），第8轮起持续保持+8优势至终局。


## 失误与改进

### 失误1: 第6轮重装2未及时撤退

**问题:** 第5轮末重装2(2,-2)已暴露于敌方3个单位（重装(2,-1)、步兵(3,-2)、未来游侠(3,-3)）的交叉火力中。第6轮敌方集火将其打至21 HP，第7轮被游侠补刀击杀。

**改进:** 第5轮末应主动将重装2撤退到(0,-3)（墙后已爆破区域）或(1,-3)（重装2曾在此埋伏过），规避敌方集结。

**预期收益:** 重装2存活 → 终局时可双线作战（一个重装守家+一个重装攻HQ），或更快结束游戏。当前实际是单重装孤军奋战，被迫加速突击节奏。

### 失误2: 第7轮重装2撤退晚了1格

**问题:** 第7轮重装2从(2,-2)撤退到(1,-3)，但(1,-3)仍在敌方游侠(3,-3)攻击范围内（距离2，游侠射程3），被敌方下一回合(其实是同时回合)击杀。

**改进:** 应直接撤退到(0,-4) 或 (0,-3)（已爆破安全区），或 (1,-2)（墙洞后方但近cp_e争夺区）。

**预期收益:** 保住重装2生命 → 第9-11轮有2个重装可同时攻击敌方HQ，3轮可减少到2轮（HQ 100 → 0 只需2次满伤害）。

### 失误3: 第4轮重装未移动足够多格以获得更佳攻击位

**问题:** 第4轮重装1从(-1,2)移到(1,2)仅2格（实际可移动3格），没能直接跳到(2,2)。导致第5轮才到达(2,2)击杀敌方侦察兵，多用1轮。

**改进:** 第4轮重装1直接移动(-1,2)→(0,2)→(1,2)→(2,2) 3格，立即攻击敌方(3,2)侦察兵。

**预期收益:** 提前1轮击杀敌方侦察兵 → 敌方更早失去墙洞区域控制，第5轮我方重装2也可提前展开攻势。

### 胜利关键因素
1. **第1轮抢占 cp_nw**：先手经济基础 +20/轮收入，全程累计 +220 收入优势

> **"先抢最高收入据点，再多路并进破墙，最后集火突破；双人局重装不可分兵——保一个换三个据点。"**

**第1轮抢占 cp_nw 建立经济统治，第2-3轮双线爆破打通墙洞，第5轮击杀敌方突破侦察兵压制信息战，第7轮战略撤退保住经济优势，第8-11轮单重装孤军突击敌方 HQ 完成致命三连——双人局破障行动的教科书级经济压制 + 集中突击战。**
