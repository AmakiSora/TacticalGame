## 核心胜利策略

### 1. 墙壁爆破与通道控制

**关键决策:** 第2轮集中火力爆破中央墙壁[0,2]，打开通往敌方区域的通道。

```text
第2轮 / player_a: 重装[4,2]→[1,2]（1 AP），然后爆破[0,2]（免费动作，已激活）
第2轮 / player_a: 同一重装已激活，爆破后变为"已行动"状态
结果: 墙壁[0,2]从blocker变为plain，打开通道
事件依据: #21 move, #22 demolish
```

**为什么有效:**
- 中央墙壁（q=0，r=-7至r+7）完全隔断东西两侧，只有r=-8和r=8处有天然缺口
- 爆破[0,2]创造了最近的通道，使我方单位能快速进入敌方区域
- 敌方也爆破了[0,-2]，但我方率先完成爆破并推进

### 2. 重装消耗战

**关键决策:** 利用重装的高攻击力（40）持续消耗敌方重装，最终全部消灭。

```text
第3-8轮 / player_a: 重装[-1,2]/[-2,2]持续攻击敌方重装[-2,2]/[-3,2]
第7轮: 敌方重装HP降至35/150
第8轮: 重装[-2,2]攻击[-3,2]，击杀！（#127 unit_death）
第9-11轮: 重装[5,0]/[6,0]持续攻击敌方重装[6,0]/[7,0]
第11轮: 重装[6,0]攻击[7,0]，击杀！（#189 unit_death）
```

**为什么有效:**
- 重装攻击力40，敌方重装防御13，每次造成27点伤害
- 两个重装交替攻击，高效消耗敌方重装HP
- 消灭敌方重装后（共2个），敌方失去核心攻击单位

### 3. 控制点争夺与经济优势

**关键决策:** 反复争夺cp_e（东部维修站），并在最后阶段占领cp_w（西部维修站）。

```text
第1轮: 占领cp_se（东南补给站）→ +20收入/轮
第2轮: 占领cp_ne（东北前线基地）→ 部署折扣8
第5轮: 占领cp_e（东部维修站）→ +8收入/轮
第8轮: 敌方占领cp_e → 我方收入下降
第11轮: 夺回cp_e → 恢复收入
第15轮: 占领cp_w（西部维修站）→ 4个控制点！
```

**为什么有效:**
- 每个控制点价值90分（裁决权重）
- 控制4个点 vs 敌方2个点 = 180分优势
- 补给站收入20/轮，维修站收入8/轮，前线基地提供部署折扣

### 4. HQ防御与反击

**关键决策:** 第11轮当敌方重装[7,0]威胁HQ时，立即击杀。

```text
第10轮 / player_b: 敌方重装[6,0]→[7,0]，然后攻击我方HQ（#178 attack）
```

- 但击杀敌方重装消除了持续威胁
- 我方HQ虽然受损（60HP = 120分），但保持了存活

### 5. 最终突破与胜利锁定

**关键决策:** 第14-15轮，派遣步兵穿越墙壁占领敌方控制点cp_w。

## 失误与改进

### 失误1: 重装不能占领控制点

**问题:** 第2轮将重装移动到cp_ne[4,-3]，但重装不能占领控制点，浪费了1个AP的推进机会。
**改进:** 应记住只有步兵和侦察兵能占领控制点，重装移动到CP位置是无效占点。
**预期收益:** 如果第2轮用步兵而非重装去占cp_ne，可节省1个AP用于其他行动。

### 失误2: 第11轮前HQ防御空虚

**问题:** 第6-10轮间，敌方重装从[4,0]逐步推进到[7,0]并攻击HQ，我方未能及时阻止。
**改进:** 应在敌方重装接近HQ时（距离2-3格时）立即回防，而非继续在前线消耗。
**预期收益:** 避免40点HQ伤害（=200分），同时可保持前线压力。

### 失误3: cp_e反复易手

**问题:** cp_e在第5-11轮间多次易手（我方→敌方→我方），浪费了大量行动力。
**改进:** 占领cp_e后应部署单位防守，而非全部用于进攻。或者接受cp_e的反复争夺，将资源集中在其他目标。
**预期收益:** 减少无效的反复占点行动，节省AP用于推进或防守。

### 失误4: 第14-15轮推进速度不足

**问题:** 步兵穿越墙壁后推进速度慢（每轮3格），未能更早到达敌方控制点。
**改进:** 应更早（第10-12轮）派遣侦察兵（移动5）穿越墙壁，而非等到第14轮才用步兵（移动3）。
**预期收益:** 更早占领敌方CP，扩大经济优势。
