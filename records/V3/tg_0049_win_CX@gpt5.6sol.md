## 核心胜利策略

### 1. 两名侦察兵抢双维修点，把前哨折扣转成五点经济

**关键决策:** 第1轮额外部署侦察兵，第2轮先占北岭前哨，第3轮由两名侦察兵同时占领(-2,-3)与(2,3)。

```text
第1轮 / player_b: HQ部署侦察兵至(-4,4)，35补给（seq6）
第2轮 / player_b: 原侦察兵占cp_fb_a(-2,-2)（seq21、25）
第3轮 / player_b: 原侦察兵占cp_repair_a(-2,-3)，新侦察兵占cp_repair_b(2,3)（seq41、43-44）
第5轮 / player_b: 新侦察兵再占cp_fb_b(2,2)，据点达到5个（seq80、84）
```

**为什么有效:**

- `supply`、`forward_base`、`repair`每轮分别提供12、8、8补给；第5轮后五点带来44据点收入，加基础10即54/轮。
- 北岭前哨的8点部署折扣被使用7次，共节省56补给；折扣使64费游骑兵、80费重装和27费侦察能够嵌入整数补给曲线。
- 双维修点不是额外裁决类型分，但每个仍值75据点分；东维修站还累计修复51HP，其中侦察兵11HP、重装40HP（seq55、76、115、136、155、176）。

### 2. 先压血线再集中收割，优先删除高价值单位

**关键决策:** 不平均分散伤害，而是连续两轮完成敌侦察与敌重装的击杀链。

```text
第3-5轮: 侦察13 + 侦察14 + 重装30，敌侦察58→1；第5轮重装补刀击杀（seq39、57、59、78-79）
第4-6轮: 三次游骑攻击27、25、30、30，敌重装140→0（seq61、81、83、97-99）
第7-8轮: 游骑先打39至29HP，下一轮另一游骑打36完成击杀（seq118、138-140）
第7-9轮: 重装31、29、32连续攻击，敌步兵90→0（seq120、141、158-159）
```

**为什么有效:**

- 最终我方击杀4个敌单位：侦察、重装、游骑兵、步兵；对手击杀我方3个单位。
- 敌重装价值88且能拆墙、近战压点，第6轮删除它后，对手再无重装，无法把中央障碍转化为HQ进攻通道。
- 每次移动后攻击仍只消耗该单位一次激活，例如seq58-59、60-61、138-139；4行动点因此能覆盖更多有效动作。

### 3. 让残血游骑兵换取34点HQ伤害

**关键决策:** 第8轮把游骑兵推进到(2,-2)，击杀29HP敌游骑兵后承受两次攻击仍剩8HP；第9轮立即攻击HQ(5,-5)。

```text
第8轮 / player_b: ranger (0,-2)→(2,-2)，击杀enemy ranger(3,-1)（seq138-140）
第8轮 / player_a: infantry与ranger合计造成60伤，ranger 68→8HP（seq147-148）
第9轮 / player_b: 8HP ranger攻击player_a HQ，造成34，HQ 100→66（seq157）
第9轮 / player_a: infantry补刀，ranger阵亡（seq166-167）
```

**为什么有效:**

- 34点HQ伤害按权重7贡献238分，同时使对手己方HQ项减少68分（34×2），一次攻击造成306分相对摆动。
- 该游骑兵最终必然处于高危区，优先攻击HQ比撤退或打普通单位更符合第9轮裁决权重。
- 对手第8轮把第3、4次激活用于部署和移动，没有完成补刀，形成了可被立即兑现的窗口。

### 4. 终局按“军力×2 - 补给”计算部署净收益

**关键决策:** 第10轮用恰好80补给从南岭前哨部署88价值重装，同时把可被远程击杀的单位撤出覆盖。


**为什么有效:**

- 重装部署令军力价值增加88，即增加176裁决分；花掉80补给损失80分，净增96分。
- 支援自疗让其最终折算军力由约8升到24；同一次激活继续移动，没有额外消耗行动点。
- 撤退后的三个单位没有在对手最终回合承伤；对手四次动作只完成三次移动和一次部署（seq186-189），无法削减我方1853分。

## 失误与改进

### 失误1: 第7轮只压低敌游骑兵，未形成当轮击杀

**问题:** 第一名游骑兵从(-1,-2)进入(1,-2)并把目标打到29HP（seq117-118），第二名游骑兵却只从(-2,-1)移动到(0,-2)，没有产生攻击事件（seq119）。对手随后用两名游骑兵合计70伤击杀前者（seq126-128），我方损失72价值单位；目标直到第8轮才被另一游骑击杀。

**改进:** 当第二火力无法在合法射程内补刀时，不应先把第一名满血游骑兵送入两支敌远程单位的交叉火力。可延后一次齐射，或先让维修重装和占点单位改变敌军站位，再以两单位同时进入射程完成击杀。

**预期收益:** 在对手响应不变的假设下，至少避免一名72价值游骑兵被立即删除，终局军力项最多可多144分；实际收益取决于对手是否改用火力攻击其他单位。

### 失误2: 第8轮支援部署的终局分转换不如后排游骑兵序列

**问题:** 第8轮花48部署支援（seq142），其后被两次远程攻击打到12HP（seq169、171），虽在第10轮自疗到34HP，但最终仅折算24军力价值。第8-10轮用于新增单位的总资源为155（55起始补给+46+54收入），实际部署“支援48+侦察27+重装80”，新增最终军力24+35+88=147。

**改进:** 若第8轮改为折价侦察27、第9轮折价游骑64、第10轮再折价游骑64，正好同样花155补给，理论新增军力35+72+72=179。三者都可部署在西侧前哨安全格，降低被集中削血的概率。

**预期收益:** 在假设对手行动不因部署变化而重定向、两名游骑保持满血的条件下，终局军力多32，即总分约多64。该数值是反事实估算，不是回放事实；实际支援还吸收了对手两次激活，具有未计入的节奏价值。

### 失误3: 南岭前哨缺少可占领单位接防

**问题:** 南前哨侦察兵在第6轮被击杀（seq105-108）后，我方附近只有不能占点的维修重装。对手步兵第7轮走到(2,2)并夺点（seq129-131），使我方下一轮收入由54降至46（少8），对手下一轮收入由22升至30（多8），形成至少16补给的单轮经济摆动；我方直到第9轮才夺回（seq160、162）。

**改进:** 在前哨占领者降至20HP时就触发“捕获单位接替”条件：提前让(-4,2)步兵向(-1,2)推进，或在南前哨附近折价部署步兵，而不是让该据点只由残血侦察单独维持。

**预期收益:** 若能阻止seq131的夺点，可保住8点己方收入、拒绝对手8点收入，并避免两轮75分据点项波动；需要以少一次扩军或前线攻击为代价，是否净赚取决于替换动作。
