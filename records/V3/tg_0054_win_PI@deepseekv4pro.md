## 核心胜利策略

### 1. 抢先出重装兵，直线突破挡墙

**关键决策:** 第4回合攒够50补给立即部署重装兵，而非花钱部署侦察兵。

```text
第3轮 / player_a: 补给40，不部署任何单位，省钱（侦察兵38，步兵45，都不够50）
第4轮 / player_a: 补给54，部署重装兵至(2,1)，花费50，剩余4
第4轮 / player_b: 补给60，部署重装兵至(-2,-1)，花费50，剩余10
```

**为什么有效:**
- 危险距离地图的核心机制是"空心挡墙阻断双方HQ"，只有重装兵能爆破挡墙
- 虽然双方都在第4轮部署了重装兵，但关键在于第5轮的路径选择
- 我方选择直线突破：爆破(1,1)→(0,0)→爆破(-1,0)→攻击(-2,0)，共需2次爆破
- 敌方选择南下绕路：(-2,-1)→(0,-3)→(1,-5)→(3,-5)→(3,-3)→(3,-1)，绕了6步才到我方HQ附近
- 路径效率差距：我方2次爆破4步到位 vs 敌方绕路6步，我方领先2回合到达攻击位置

### 2. 爆破-移动-攻击连招，最大化1行动点效率

**关键决策:** 在同一回合内利用"已激活单位的后续行动免费"规则，爆破后立即移动占领新位置。

```text
第5轮 / player_a: 爆破(1,1) → 移动至(1,1)（同一单位，爆破已激活，移动免费）
第6轮 / player_a: 移动至(0,0) → 爆破(-1,0)（同一单位，移动已激活，爆破免费）
第7轮 / player_a: 移动至(-1,0) → 攻击敌方HQ（同一单位，移动已激活，攻击免费）
```

**为什么有效:**
- 每回合仅1行动点，但同一单位激活后可以执行多个合法动作（移动、爆破、攻击、治疗）
- 每次爆破后立即推进，不浪费回合在"只爆破不移动"上
- 第6轮的一个失误：移动至(0,0)后爆破(-1,0)，想再移动到(-1,0)时被拒绝（"already moved this turn"），说明移动-爆破-移动的顺序中，第二次移动被禁止。正确顺序应该是爆破-移动-攻击
- 尽管如此，整体节奏仍比敌方快2回合

### 3. 早期抢占经济据点，保障长期收入

**关键决策:** 第2轮立即占领cp_2（supply类型，+8收入/回合）。

```text
第1轮 / player_a: 侦察兵移至(3,-1)，距离cp_2仅1格
第2轮 / player_a: 侦察兵移至(3,0)，回合结束占领cp_2
```

**为什么有效:**
- 基础收入仅6/回合，占领supply据点后收入翻倍至14/回合
- 第4轮即可攒到54补给（20初始 + 6×2 + 14×1 ≈ 54），刚好够部署重装兵
- 双方经济对称，但先手优势让我方在第5轮先发起攻击

## 失误与改进

### 失误1: 第6轮移动顺序错误导致浪费一次移动

**问题:** 第6轮先移动至(0,0)，再爆破(-1,0)，想再移动到(-1,0)时被拒绝（"already moved this turn"）。正确的顺序应该是：爆破(-1,0)（激活单位）→ 移动至(-1,0)（免费）。我当时的顺序是移动→爆破→移动，但移动只能在每回合执行一次。

**改进:** 今后在爆破+移动组合中，如目标格是空地，应先爆破后移动；如目标格是爆破目标本身，应先移动后爆破。记忆口诀：**"先行动后移动，爆破在前路自开"**。

**预期收益:** 节约1回合——如果第6轮成功移动到(-1,0)，第7轮就可以直接攻击，整体节奏再快1回合。

### 失误2: 第9轮敌方反攻时未部署防御单位

**问题:** 第9轮敌方重装兵到达(3,-1)并攻击我方HQ造成34伤害。我方在该回合之前累积了74补给，但从未部署第二单位（如步兵或侦察兵）来防御HQ或拦截敌方重装兵。

**改进:** 在HQ受威胁时，即使行动点有限（每回合仅1点），也应考虑部署一个单位在HQ附近。例如在第8轮用补给部署步兵在(2,1)或(1,1)，可以阻挡敌方重装兵的前进路径，或至少消耗敌方一个行动点来处理。

**预期收益:** 可能减少20-34点HQ伤害，保持HQ在更高血量。

### 失误3: 未及时清理敌方侦察兵

**问题:** 敌方两个侦察兵始终在(-3,0)和(-3,2)附近，控制着cp_1（+8收入/回合）。我方从未尝试攻击或驱逐这些侦察兵来夺取cp_1。

**改进:** 在突破挡墙后，可以分出一个侦察兵去攻击敌方cp_1上的侦察兵（攻击16 vs 防御4，伤害约12），夺取第二个据点将增加我方的收入优势并削弱敌方经济。

**预期收益:** 多一个据点+8收入×剩余回合数，以及裁决分+30（控制点权重30）。

## 总结

### 胜利关键因素
1. **直线突破 > 绕路:** 2次爆破（(1,1)和(-1,0)）直接打通通往敌方HQ的路线，比敌方绕路策略快2回合到达攻击位置
2. **行动点效率最大化:** 每回合用爆破-移动或移动-攻击连招，1个行动点完成2个动作
3. **早期经济保障:** 第2轮占领supply据点，收入翻倍，第4轮即可部署重装兵
4. **先手优势:** 作为player_a（先手），每轮先行动，率先到达攻击位置并持续压制

### 核心战术原则
> **"在危险距离地图上，挡墙就是时钟——谁先爆破挡墙到达敌方HQ，谁就赢得比赛。绕路等于认输。"**

### 一句话总结
**危险距离地图的核心是"挡墙突破速度竞赛"：直线爆破2次挡墙直达敌方HQ，比绕路绕行快2回合，在1行动点/回合的限制下，2回合的差距就是胜利与失败的距离。**
