## 核心胜利策略

### 1. 先手直插心脏 — 放弃经济、全力rush

**关键决策:** 放弃抢占己方侧 `cp_1(-3,0)`，将两个侦察兵全部投入敌HQ方向的直线冲锋。

```text
第1轮 / player_b: S1(-5,5)→(-4,5) — 直线前推
第2轮 / player_b: S1(-4,5)→(-1,4) — 3步冲刺
第3轮 / player_b: S1(-1,4)→(2,1) — 抵达HQ邻格
第4轮 / player_b: S1(2,1) 攻击HQ — 首次命中
```

**为什么有效:**
- 危险距离图的裁决权重中，`enemyHqDamage=20` 是最高权重（`controlPoint=30` 但需占领，`armyValue=1` 收益低，`supplies=0` 无收益）。
- 侦察兵成本仅38，HP 65，足够在重装掩护下存活4-5轮攻击。
- 敌方选择了对称rush策略（S2直冲我方HQ），如果我方先占cp_1再推进，会浪费2-3轮节奏。
- 先手优势 + 直线冲锋 = R4即可输出，而对手要到R10才有重装上线，中间6轮我方可输出约70+ HQ伤害。

### 2. 接力输出 — S1阵亡后S2无缝衔接

**关键决策:** S2不参与早期战斗，保存完整HP等待接替。

```text
S1阵亡: 第9轮（HP 8 → 0），累计输出 15+12+11+12+9 = 59点HQ伤害
S2接棒: 第12轮开始攻击，第12-13轮再打 9+12 = 21点
总HQ伤害: 80点（直接）+ 11点溢出 = 91点
```

**为什么有效:**
- 1AP/轮机制下，单位存活=输出，阵亡=沉默。S2全程未参战保持65HP，接替后立即生效。
- S1在R4-R8坚持了5轮输出（敌方每轮也打S1一次），拖住了敌方节奏。
- S2抵达(2,1)时敌方重装尚未部署完毕（刚上线在(3,0)），获得了2轮自由输出窗口（R12-R13）。

### 3. 读懂裁决权重，押注HQ伤害

**关键决策:** 全局不占任何据点（0据点 vs 敌占1个cp_2），将所有资源投入HQ攻击。

```text
最终裁决分:
  我方: HQ伤害91×20 + 己方HQ120×1 + 据点0×30 + 军力0×1 + 补给104×0 = 1940
  敌方: HQ伤害0×20 + 己方HQ29×1 + 据点1×30 + 军力126×1 + 补给150×0 = 185
```

**为什么有效:**
- 本图 `supplies` 权重为0，囤补给完全无裁决收益。
- `enemyHqDamage` 权重20是单项最高，91点伤害直接贡献1820分，占我方总分93.8%。
- 敌方虽占1个据点（30分）和保留3个单位（126分），但与我方HQ伤害差距完全无法弥补（差1755分）。
- 如果我方也分出资源占点或保单位，反而不经济——不如All-in HQ伤害。

## 失误与改进

### 失误1: 全程未抢占任何据点，零据点控制

**问题:** 全局未占领 `cp_1(-3,0)` 或 `cp_2(3,0)`，0据点得分。`cp_1` 距我方HQ仅1步，开局即可轻松占领。

**改进:** 即使选择rush策略，也应在R1或R2用S2快速占下 `cp_1`（从(-5,4)→(-4,3)→(-3,0)需2轮，但S2可以先推一步再占）。多1个据点可额外获得30分裁决分 + 每轮8补给收入。

**预期收益:** 多约30-80分裁决分（视占点轮数），并增加后续部署的经济灵活性。

### 失误2: S1阵亡后到S2接棒之间的输出空窗

**问题:** S1在R8被击杀（HP 8→0），S2直到R12才开始攻击，中间R9-R11共3轮我方无HQ伤害输出。敌方利用这段时间部署了重装。

**改进:** S1阵亡后，若S2已在推进途中，可提前1-2轮出发。或者在R7看到S1濒危时，让S2提前从(-5,4)开始移动（而不是等到R9才动）。

**预期收益:** 缩短3轮空窗期，多打约25-35点HQ伤害，加速终结。

### 失误3: 未使用任何非侦察单位

**问题:** 全局仅使用2个侦察兵（38/个），未部署步兵(45)、重装(50)、支援(60)或游骑(78)。虽然最终获胜，但阵容过于单薄。

**改进:** 若在R5-R6用剩余补给部署1个步兵（45）或支援（60），可增加一个占点/治疗单位，提高持续作战能力。

**预期收益:** 多1个单位可在S1阵亡后更快填补输出真空，同时增加 `armyValue` 裁决分（虽然本局权重仅为1）。

## 总结

### 胜利关键因素
1. **先手优势最大化** — 利用先手直接rush敌HQ，R4即开始输出，抢在对手重装部署前建立巨大伤害优势。
2. **接力输出无缝衔接** — S1吸引火力坚持5轮后，S2从后方接力，维持了连续7轮（R4-R13）的HQ压力。
3. **精准押注裁决权重** — `enemyHqDamage` 权重20是全图最高，91点伤害贡献1820分（占总分93.8%），其他项差距无关紧要。
4. **对手失误放大战果** — 敌方零HQ伤害，重装上线后仅用于防守而非反击，未能利用我方侦察阵亡的窗口期。

### 核心战术原则
> **"危险距离图先手可All-inrush：双侦察直线冲锋，R4开始输出，用敌方HQ的20倍权重碾压一切据点与军力。"**

### 一句话总结
**先手侦察双线冲锋R4开打，累计91点HQ伤害碾压对手的185分，以1940:185强制裁决获胜——纯粹的攻城对决，零花哨，零据点，纯靠贴脸输出砸穿。**
