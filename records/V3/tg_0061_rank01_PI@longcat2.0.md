## 核心胜利策略

### 1. 早期经济：四角均势开局

**关键决策:** 第1轮侦察兵5格移动占领西北补给站`cp_supply_nw`(-3,-2)，同时部署新步兵巩固基地。

```text
第1轮 / player_c: 侦察兵(-3,-5)→(-3,-2)，回合结束自动占领`cp_supply_nw`（补给型，+10收入/回合）
第1轮 / player_c: 步兵(-2,-6)→(-3,-3)推进，部署新步兵(-3,-5)
第2轮 / player_c: 侦察兵(-3,-2)→(-1,-1)占`cp_forward_nw`（前线基地，+5收入，部署折扣-5）
```

**为什么有效:**
- 四家各占一个补给站，经济均衡开局（基础8+补给10=18/回合）
- 第2轮再占前线基地后，总收入提升至8+10+5=23/回合
- 前线基地的部署折扣-5使后续部署成本降低11%（步兵45→40，侦察兵38→33）

### 2. 中央争夺持久战

**关键决策:** 第3-10轮围绕中央维修站(0,0)展开持续拉锯，虽多次易手但始终保持对`player_a`的消耗压力。

```text
第2轮 / player_d: 占中央(0,0) → 第2轮 / player_a: 夺回中央 → 第6轮 / player_a: 再占中央
第7轮 / player_c: 击杀中央旁侦察兵 → 第9轮 / player_a: 击杀我方中央步兵
第10-12轮: 持续消耗`player_a`单位，使其无法有效利用中央维修站
```

**为什么有效:**
- 中央维修站(repair型)每回合自动回复10HP，但我方持续攻击使`player_a`无法享受维修收益
- `player_a`在中央投入大量资源（部署3+个步兵+1游侠），我方通过非对称消耗使其军力价值持续下降
- 最终`player_a`军力仅163（含3个据点），而我方军力257（仅2个据点）

### 3. 重点清除高威胁单位

**关键决策:** 第9-10轮集中火力击杀`player_a`部署的游侠（攻击44，射程3）。

```text
第5轮 / player_a: 部署游侠(-2,0)，攻击力44/射程3（远超步兵30/1和侦察兵16/1）
第9轮 / player_c: 步兵(-2,-1)攻击游侠(48→21hp)
第10轮 / player_c: 步兵(-2,-1)攻击游侠(20→0hp) → 击杀！
```

**为什么有效:**
- 游侠是本局配置中单发伤害最高的单位（44攻击-3防御=41基础伤害），对我方低防御单位（侦察兵4防御）威胁极大
- 若不及时清除，游侠可从(-2,0)远程攻击我方中央单位(0,0)和前线单位(-1,-1)
- 击杀游侠后，`player_a`再无高输出单位，进攻威胁大幅降低

### 4. 终局军力冲刺

**关键决策:** 第12轮（最后一轮）同时部署2个步兵、进行2次攻击，最大化军力价值和裁决总分。

```text
第12轮 / player_c: 步兵(-1,-1)攻击`player_a`步兵(-1,0)(100→79hp)
                    步兵(-2,0)攻击`player_a`步兵(-2,1)(100→78hp)
                    部署步兵(-2,-1)（消耗40补给）
                    部署步兵(-2,-6)（消耗45补给）
```

**为什么有效:**
- 每个部署的单位增加军力价值（步兵价值90，相当于裁决分180分）
- 终局部署不担心被消灭（无后续回合），是纯粹正向的分数增长
- 攻击虽未击杀，但降低`player_a`军力价值（2×步兵从100→~78，军力下降约44点=88裁决分）
- 此轮策略使总分从~984跃升至1082，拉开第二名155分差距

## 失误与改进

### 失误1: 第6轮中央步兵阵亡后未能及时反制

**问题:** 第6轮`player_a`集中火力击杀我方驻守中央的步兵(100→77→44→0hp)，我方未能提前判断该步兵的危险性并后撤或支援。中央维修站因此重新落入`player_a`手中，导致后续3轮需要重新争夺。

**改进:** 当中央步兵HP降至60以下时，应提前部署侦察兵或另一步兵从(-1,-1)或(-1,0)方向协防，形成"双人站岗"。

**预期收益:** 若守住中央1-2轮，可提前建立军力优势，减少后续3轮的拉锯消耗。

### 失误2: 第3-5轮对`player_a`游侠反应过慢

**问题:** `player_a`在第5轮部署游侠(-2,0)后，我方直到第9轮才组织第一次攻击，第10轮才击杀。游侠在这4轮中持续造成伤害（攻击我方侦察兵从65→40→14→0hp）。

**改进:** 应在游侠部署当轮或次轮即组织集火。游侠防御仅3，步兵攻击30可造成27±3伤害，2次步兵攻击即可击杀。

**预期收益:** 提前2轮击杀游侠可减少我方侦察兵被击杀的损失（65补给单位+军力价值130），节省重新部署成本。

### 失误3: 未能利用`player_d`和`player_b`的互相消耗

**问题:** `player_d`和`player_b`在第3-8轮间激烈交战（`player_d`击杀`player_b`侦察兵、步兵），我方未在此窗口期发动决定性进攻。`player_b`的侦察兵被击杀至仅剩3HP时，我方完全可以远程补刀获取击杀分数，但选择了继续与`player_a`拉锯。

**改进:** 当两敌交战时，应评估"补刀弱敌"和"强攻主敌"的收益比。击杀残血单位可立即获得军力优势和行动点效率优势。

**预期收益:** 补刀`player_b`残血侦察兵（3HP）仅需1次侦察兵攻击（12±3伤害），即可获得军力价值+65（裁决+130分），收益极高。
