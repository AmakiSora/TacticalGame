## 核心胜利策略

### 1. 经济先行 — 抢占cp_1建立收入优势

**关键决策:** 第1-2轮用侦察S2直线抢占cp_1(-3,0)，比对手更早建立补给点收入。

```text
第1轮 / player_b: S2(-5,4)→(-3,1) — 两格推进直插cp_1方向
第2轮 / player_b: S2(-3,1)→(-3,0) — 占领cp_1，收入从6/轮提升至14/轮
第4轮 / player_a: S1(3,-2)→(3,0) 占领cp_2 — 比我方晚2轮
```

**为什么有效:**
- cp_1距我方出生scout仅2步（(-5,4)→(-3,1)→(-3,0)），而cp_2距敌方scout需3步（(5,-5)→(4,-5)→(3,-5)→(3,0)）。
- 先占2轮意味着多出16补给的收入差（8×2），这在1AP/轮的紧凑节奏中足以提前1轮部署Heavy。
- 从第3轮开始每轮14补给 vs 敌方第5轮才开始14补给，经济优势在R4时达到峰值（60 vs 32）。

### 2. 重装破墙 — Heavy攻城链

**关键决策:** R4积攒60补给后立即部署Heavy(50)，然后用2轮连续爆破2面blocker墙壁。

```text
第4轮 / player_b: 部署Heavy(-2,-1)，花费50补给
第5轮 / player_b: Heavy爆破blocker(-1,-1) → 中路第一面墙打通
第7轮 / player_b: Heavy移至(1,-1)，爆破blocker(1,0) → 敌方HQ前最后屏障清除
第8轮 / player_b: Heavy(1,0)攻击敌方HQ — 开始输出
```

**为什么有效:**
- 危险距离图的中间地带被两道blocker墙阻断：(-1,-1)和(1,0)。只有Heavy能爆破地形。
- 两次爆破间隔仅2轮（R5和R7），打通了一条从(-2,0)直到(2,0)的直线攻击通道。
- Heavy攻击力40（vs scout的16），每次对HQ伤害约33-38点，4次攻击即可摧毁120HP的HQ。

### 3. 经济碾压 — 收入优势转化为攻城节奏

**关键决策:** 利用cp_1的收入优势，在敌方部署ranger(78)的同时仍有足够补给维持攻势。

```text
R4: 我方60补给，部署Heavy(-50) → 剩10
R7: 我方52补给，敌方52补给 — 敌方花78部署ranger后仅剩2！
R8: 敌方16补给 vs 我方66补给 — 经济差距62
```

**为什么有效:**
- 敌方部署ranger花费78后补给跌至2，几乎丧失后续部署能力。
- 我方R7时52补给无需额外花费（爆破不消耗补给），R8恢复到66。
- 全程我方补给从未低于10，始终保持行动自由。

### 4. 无视骚扰 — Heavy硬扛ranger火力持续攻城

**关键决策:** 面对ranger(射程3，攻击44)的骚扰，不撤退、不反击，坚持每轮轰击HQ。

```text
第9轮: ranger攻击Heavy 32伤害(150→118)，Heavy反击HQ 33伤害
第10轮: ranger攻击Heavy 32伤害(118→86)，Heavy反击HQ 37伤害
第11轮: ranger攻击Heavy 34伤害(86→52)，Heavy反击HQ 38伤害 → 终结
```

**为什么有效:**
- Heavy HP 150，ranger每轮仅32-34伤害，至少需要5轮才能击杀Heavy。
- 但Heavy对HQ每轮33-38伤害，R8开始攻击时HQ 120HP，仅需4轮即可摧毁。
- 4轮 < 5轮，Heavy能在被击杀前完成攻城任务。实际Heavy以52HP存活，余量充足。

## 失误与改进

### 失误1: 第6轮Heavy移动路线不够激进

**问题:** R6将Heavy从(-2,-1)移到(0,-1)，仅前进2格。如果直接移到(1,-1)需要3格路径但Heavy移速仅2。实际上(-2,-1)→(0,-1)是最优2步路径，但浪费了后续等待时间。

**改进:** 移动后应立即结束回合（实际执行中因等待过长导致对手以为我没结束回合）。在1AP/轮的限制下，每个动作的时间效率至关重要。

**预期收益:** 减少对手思考时间，加快对局节奏。实际未造成战术损失。

### 失误2: 侦察S1全程无用

**问题:** S1在R3移到(-3,2)后全程未动，未参与任何战斗、占点或有意义的行动。38价值的单位完全浪费。

**改进:** S1应在R5-R6向敌方HQ方向推进，或尝试抢占中立据点/干扰敌方。即使无法直接参战，至少应作为前进观察哨或潜在占点单位。

**预期收益:** 若S1参与后期围攻，可增加军力价值裁决分（armyValue×1=1分/单位价值），并可能在Heavy被击杀后接力输出。

### 失误3: 未利用经济优势部署第二单位

**问题:** 最终补给108（全场最高），但全局仅部署1个Heavy(50)。剩余的58补给完全囤积，`supplies`裁决权重为0，零收益。

**改进:** R8-R9时可考虑部署1个步兵(45)或侦察(38)作为后续接力或占点。即使来不及参战，至少增加armyValue裁决分。

**预期收益:** 多部署1个步兵(45)：花费45补给，增加100 armyValue → +100裁决分，同时保留63补给。

## 总结

### 胜利关键因素
1. **经济优先** — R2抢占cp_1，每轮多8补给，11轮累计多收72补给，支撑R4的Heavy部署。
2. **重装攻城** — Heavy攻击力40是scout的2.5倍，4轮120伤害直接摧毁HQ，效率远超scout rush。
3. **双墙连破** — R5和R7两次爆破打通中路，为Heavy建立直线攻击通道。
4. **硬扛反击** — Heavy 150HP扛住ranger 3轮98伤害，以52HP存活完成任务。

### 核心战术原则
> **"危险距离后手走经济Heavy流：R2占点建立收入优势，R4出Heavy，两墙连破，R8开始轰HQ。Heavy每轮33+伤害，4轮摧毁120HP的HQ。"**

### 一句话总结
**后手经济Heavy流11轮摧毁敌方HQ——占点+8/轮收入支撑重装部署，两次爆破打通中路，4轮120点HQ伤害一击毙命，2643:0完胜。**
