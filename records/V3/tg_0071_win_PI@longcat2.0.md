## 核心胜利策略

### 1. 快速破障打开进攻通道

**关键决策:** 利用重装在3轮内爆破中央石墙(q=0)，建立直通敌方领土的通道。

```text
第3轮 / player_a: 重装1爆破(-1,1)，重装2爆破(-1,1)，打开q=-1层墙壁
第4轮 / player_a: 重装1→(-1,1)，重装2→(-1,-1)，爆破(0,1)和(0,-1)，打通q=0层
第8轮 / player_a: 重装2爆破(1,-1)，打通q=1层，完成穿越
```

**为什么有效:**
- 中央石墙(q=0)完全阻断直射路线，唯一通道是绕行地图边缘或通过爆破
- 绕行边缘需要6-8轮，而爆破仅需3轮即可打通
- 重装移动力3，恰好可以在一轮内到达墙壁并爆破
- 早期破障为后续重装直扑HQ奠定基础

### 2. 重装突袭敌方HQ

**关键决策:** 重装2穿越墙壁后全速向敌方HQ(8,0)推进，8轮内完成从(0,-1)到(8,-1)的7格距离。

```text
第4轮 / player_a: 重装2→(-1,-1)，穿过墙壁
第6轮 / player_a: 重装2→(1,-1)，进入敌方领土
第8轮 / player_a: 重装2→(3,-1)，继续推进
第9轮 / player_a: 重装2→(6,-1)，距HQ仅2格
第10轮 / player_a: 重装2→(8,-1)，紧邻敌方HQ
第11-13轮 / player_a: 重装2连续三次攻击HQ，每次40伤害，最终摧毁
```

**为什么有效:**
- 敌方专注于占领据点和渗透我方领土，未及时回防HQ
- 重装攻击力40，HQ防御0，每次稳定造成40伤害
- HQ仅100HP，3次攻击即可摧毁
- 标准模式下HQ摧毁即获胜利，无需考虑裁决分

### 3. 据点争夺与防御反击

**关键决策:** 开局快速占领3个据点(cp_nw, cp_w, cp_sw)建立经济优势，后期虽被敌方夺取cp_sw和cp_w，但通过击杀夺回。

```text
第1轮 / player_a: 侦察兵→cp_nw(-4,3)，占领西北补给站
第2轮 / player_a: 侦察兵→cp_w(-3,0)，占领西部维修站
第3轮 / player_a: 侦察兵→cp_sw(-4,3)，占领西南前线基地
第5-7轮 / player_b: 敌方侦察兵夺取cp_w，步兵夺取cp_sw
第7-8轮 / player_a: 步兵+侦察兵集火消灭敌方侦察兵，夺回cp_w
```

**为什么有效:**
- 3个据点提供稳定的收入来源（补给站+20/回合，维修站+8/回合，前线基地+8/回合）
- 前线基地提供部署折扣(-8)，降低后续部署成本
- 及时击杀夺回cp_w，减少敌方经济收入

## 失误与改进

### 失误1: 未及时防御cp_sw前线基地

**问题:** 第3轮占领cp_sw后，第5轮被敌方侦察兵(-4,3)夺取，损失约2回合的据点收入（约16补给）。
**改进:** 占领cp_sw后应部署一个单位留守，或在第4轮时侦察兵继续留守而非全部出击。
**预期收益:** 保留cp_sw的8收入/回合，15轮可多获得约120补给。

### 失误2: 重装2穿越后推进速度偏慢

**问题:** 重装2从(0,-1)到(8,-1)耗时5轮（第6-10轮），期间未充分利用每回合3的移动力。
**改进:** 应更早规划直线路径，避免在第7-8轮时因处理敌方渗透单位而分心。
**预期收益:** 提前2轮到达敌方HQ，减少敌方反应时间。

### 失误3: 未充分利用前线基地部署折扣

**问题:** cp_sw前线基地提供8点部署折扣，但本局仅在该据点被占领期间部署了1个侦察兵，节省8补给。
**改进:** 在前线基地被占领期间，应集中部署多个单位以最大化折扣收益。
**预期收益:** 若部署3个单位可节省24补给。

## 总结

### 胜利关键因素
1. **快速破障:** 3轮内打通中央墙壁，建立进攻通道
2. **重装突袭:** 重装2穿越后全速推进，8轮内抵达敌方HQ

### 核心战术原则
> **"破墙、突进、斩首——据点数不是胜利的唯一途径"**

### 一句话总结
**通过精准的破障时机选择和重装长途奔袭，在敌方积累足够裁决分优势前完成斩首，实现以弱胜强的经典逆转。**
