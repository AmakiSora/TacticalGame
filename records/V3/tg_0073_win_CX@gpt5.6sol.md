## 核心胜利策略

### 1. 两轮双点、三轮三点，先取得经济与部署权

**关键决策:** 初始4单位不是堆在一条走廊，而是两名侦察兵分别承担北线补给站与南线前线基地。

```text
第2轮 / player_a: 侦察兵到cp_nw(-2,-4)和cp_sw(-6,4)，回合末双占点（seq20-25）
第3轮 / player_a: 北侦察兵继续到cp_nc(2,-4)，新增第三点（seq41、45）
第4轮 / player_a: 南侦察兵进入cp_sc(-2,4)，从player_b手中夺点（seq65、68）
```

**为什么有效:**

- `cp_nw`每轮提供12补给，`cp_sw`每轮提供8补给并让每次部署省8；两者在第2轮同时生效，经济和投送没有互相等待。
- 对手虽在第4轮夺走`cp_nw`、中盘争夺`cp_nc`，我方始终保住`cp_sw`，因此扩军链没有中断。
- 全局14次收入共608，其中基础收入140、据点收入468；最终可用总补给达到816。

### 2. 北线“侦察占点+游骑兵掩护”，南线“步兵接触+游骑兵收割”

**关键决策:** 把可占点的高速侦察兵留在北线长距离往返，把步兵密度和后续游骑兵投入南线近身消耗。

```text
北线: cp_nw(-2,-4)→cp_nc(2,-4)→cp_ne(6,-4)→敌HQ邻格(7,-1)
南线: cp_sw(-6,4)持续部署，部队沿r=3/4推进至cp_sc(-2,4)及q=0..3接触区
```

**为什么有效:**

- 侦察兵移动5，恰好适合跨越北线三个据点；游骑兵射程3能在不占点的情况下清除北线侦察兵。
- 南线障碍使近战单位容易拥堵，游骑兵从后方提供38-42级别实际伤害，多次把目标压入步兵补刀线。
- 两线职责分开后，对手的侦察兵海无法同时挡住占点、南线集火和HQ渗透。

### 3. 集火到击杀，不把伤害平均摊给多个可行动单位

**关键决策:** 每轮优先删除已经进入必杀区间的单位，再切换新目标。

```text
第4轮: 13+29+23实际伤害，击杀65HP侦察兵（seq59-64）
第9轮: 20实际伤害完成42→20→0的步兵击杀链（seq151、168-170）
第12轮: 38+25+2实际伤害，击杀65HP突入侦察兵（seq239-244）
第13轮: 25+33+25+2实际伤害，击杀85HP步兵（seq261-269）
```

**为什么有效:**

- 全局击杀9个单位（侦察兵7、步兵2），只损失3个单位（步兵2、侦察兵1）。
- 每次击杀都同时降低对手下一回合的输出、占点能力和终局军力价值；这比把多个目标都打成残血更稳定。
- 最终军力718:237，按×2权重直接形成962分优势，是最大单项分差。

### 4. 折价部署贯穿中后盘，终局不留闲置补给

**关键决策:** 从第3轮起优先使用`cp_sw`，第15轮再把最后70补给换成折价游骑兵。

```text
全局部署: 侦察兵2、游骑兵6、步兵8，共16次
前线基地部署: 11次，每次折扣8，共节省88
总可用补给: 初始208 + 收入608 = 816
实际部署支出: 816；最终补给: 0
```

**为什么有效:**

- 单位标价合计904，实际只花816；88点折扣相当于额外获得一名78费游骑兵后仍多10点价值空间。
- 裁决中军力价值×2、补给仅×1；第15轮将70补给变成满血78价值游骑兵，静态分从70提高到156，另有部署行动分。
- 与第49局的“终局补给转军力”经验一致，本局做到精确归零。

### 5. 五点控制后持续打HQ，把局面优势转换成多分项优势

**关键决策:** 第9轮夺取`cp_ne`后，北侦察兵在`cp_ne`与(7,-1)之间往返，攻击后退回安全区。

```text
第10-15轮HQ伤害: 11、12、12、9、13、10，共67（seq191、216、238、259、285、305）
裁决收益: 67×4=268分，同时敌HQ由180降至113，使其己方HQ项再少134分
```

**为什么有效:**

- 单次激活同时完成移动、攻击和撤离，不额外消耗行动点，复用了第36局验证过的同单位连续动作原则。
- 对手必须在北线侦察威胁、南线据点和扩军之间分散行动，而我方HQ始终180/180。
- 五点不是静态守分；其收入继续转军力，前沿位置继续转HQ伤害，优势在多个裁决项同步增长。

## 失误与改进

### 失误1: 第10轮让两名残血步兵同时留在反击范围

**问题:** 我方两名步兵在第10轮行动后分别约49HP与9HP。对手用游骑兵39伤加侦察兵10伤击杀前者（seq203-205），再由另一侦察兵9伤击杀后者（seq208-210）。按阵亡前HP折算，二者约保有`round(45×49/100)+round(45×9/100)=22+4=26`军力价值，即52裁决分。

**改进:** 完成南线击杀后，优先把49HP步兵从(3,2)撤到敌游骑兵射程外；9HP步兵若无法安全撤离，应避免为13点补刀站到(0,2)，改由后排游骑兵完成击杀或接受下一轮再收割。动作前应同时画出敌游骑兵射程3和侦察兵移动5后的接触区。

**预期收益:** 至少保存一名残兵时，可保留约22军力价值，即44裁决分；若两者均存活则约52分。该估算只按当时HP计算，不假设后续治疗。

### 失误2: 第11轮没有撤走48HP的维修点侦察兵

**问题:** `cp_sc`在回合开始为该侦察兵维修10HP，使其到48HP（seq214）；我方随后把5个激活位全部用于HQ侦察兵、部署和三支后续部队移动。对手侦察兵13伤加游骑兵35实际伤害将其击杀（seq225-229）。其阵亡前军力价值约为`round(38×48/65)=28`，即56裁决分。

**改进:** 第11轮应把一个后方游骑兵前移动作换成该侦察兵撤退，利用移动5离开南线游骑兵射程；新部署步兵已可在下一轮进入`cp_sc`接替维修与卡点。领先局终局排序应是“确定击杀/HQ分→撤高残值单位→部署→普通前移”。

**预期收益:** 若只保存到裁决且不再受伤，可增加约28军力价值、56裁决分；同时减少对手一次高伤攻击带来的行动分。

### 失误3: R10-R11连续损失说明终局威胁检查没有制度化

**问题:** 三个阵亡全部发生在已经形成5:1据点优势之后，而且集中在相邻两个对手回合。胜势下仍按进攻阶段的站位容忍度行动，使我方从“几乎无损扩军”变成损失两步兵一侦察兵。

**改进:** 一旦领先至少3个据点，回合结束前固定检查：敌方每个游骑兵射程3、每个侦察兵移动5后的攻击格、己方单位HP折算军力价值。无法形成确定击杀的前移，应让位于撤退或维修轮换。

**预期收益:** 本局三名阵亡单位在死亡前合计约54军力价值，对应108裁决分；即使只能保住一半，也约有54分安全垫。该值是按死亡前快照估算，不代表一定能全部保存。
