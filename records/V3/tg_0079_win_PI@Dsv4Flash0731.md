## 核心胜利策略

### 1. 开局经济雪球——9回合8据点，收入20→60/轮

**关键决策:** 先手第1轮步兵直占 `supply_west`，第2-4轮用移动力优势把西/南/北线据点全部扫净，第7/9轮反夺敌方两处东线据点，把收入从20/轮滚到60/轮（对手峰值28/轮），总收入536 vs 272。

```text
第1轮 / player_a: 步兵(-5,0)→(-3,0) 🏴supply_west；步兵(-5,1)→(-3,2)；重装(-4,-1)→(-2,-2)
第2轮 / player_a: 步兵(-3,-1)→(0,-3) 🏴supply_northwest；步兵(-3,2)→(-3,3) 🏴supply_southwest
第3轮 / player_a: 步兵(-3,3)→(0,3) 🏴supply_southeast
第4轮 / player_a: 斥候(1,-3)→(0,-4) 🏴cp_northwest（6据点，48/轮）
第7轮 / player_a: 步兵(1,-1)→(3,0) 🏴supply_east（反夺）
第9轮 / player_a: 步兵(3,0)→(4,0) 🏴cp_east（反夺，8据点，60/轮）
```

**为什么有效:**
- 我方收入536 vs 敌272，差值264，全部转化为部署与军力：我方5次部署292补给（步兵45+斥候38+步兵45+游侠72+重装92），敌方6次部署276（斥候38×3+步兵45×2+游侠72）
- **CP 所有权不依赖驻守**（敌 `supply_east` 在 R1 被占后单位移走仍归其所有），因此占点单位可占完即走、继续扫下一片，与战斗单位不抢 AP
- 反夺敌 `supply_east`(R7)+`cp_east`(R9) 直接把敌方收入从28/轮砍到20/轮、我方升到60/轮——**抢占不如反夺**，同时把敌方部署源压缩到东北角两据点

### 2. 四单位集火斩重装——第5-7轮定点拆掉敌方唯一坦克

**关键决策:** 敌方150血重装 R3 起连续攻击我方重装（共造成107伤），我方从 R5 起用 3-4 个攻击者连续三轮集火它：R5 三击（150→97）、R6 四击（→20）、R7 一击斩杀。

```text
第5轮 / player_a: 重装22 + 步兵15 + 步兵16 → 敌重装150→128→113→97
第6轮 / player_a: 重装27 + 步兵20 + 步兵16 + 步兵14 → 70→50→34→20
第7轮 / player_a: 残血重装(6HP) 攻20 → 💀敌重装阵亡（随后被敌步兵反杀）
```

**为什么有效:**
- 敌方重装是全场唯一肉盾（150血/38攻），放任它每轮输出25-28伤会持续吃掉我方前排；用4个单位3轮集中打掉，比我方被动接招划算
- 第7轮我方重装仅6血（必死资产），用它换掉敌方满血重装是**残血换健康**的高杠杆兑换——我方实际净损1个将死的单位，敌方净损1个健康坦克
- 敌方重装死亡后，敌方正面再无承伤单位，其4个步兵/斥候全是贴脸1格，我方游侠（射程3）进入单方面压制

**关键决策:** 敌方重装被斩后，其东侧防线空虚：R7 步兵 7d191a74 直插 (3,0) 反夺 `supply_east`；R9 继续前压 (4,0) 击杀驻守步兵并反夺 `cp_east`。

## 失误与改进

### 失误1: 两个单位全程驻守据点吃炮击，白白损失100血

**问题:** 据点所有权不依赖驻守（敌方 R1 占 `supply_east` 后单位离开、据点仍归其所有，直到 R7 被我反夺），但我方把两个单位长年钉在据点上：步兵 9628f8e5 自 R3 占领 `supply_southeast`(0,3) 后 10 轮未动，斥候 23de8b4b 自 R8 起停在 `supply_northwest`(0,-3)。R11 收缩到2后 (0,3)/(0,-3)（dist 3）双双进危险区，两单位各吃2轮边界炮击：9628f8e5 100→50、23de8b4b 65→40→26（还被敌斥候打到1血）。**合计100血可避免炮击**，且这两个单位全程未参与战斗（9628f8e5 直到 R12 才攻击一次）。

**改进:** 占点后立即撤离，把“驻守”改成“路过占点”；收缩当轮核对 `safeRadius`，把 dist > 新半径 的单位列清单内移。这两点与 tg_0078 的撤离教训同源（见对比结论）。

**预期收益:** 9628f8e5 保持100血并可从 R9 起参加中心战斗（+22军力价值），23de8b4b 保持65血免于阵亡（R12 它死因就是1血被收割）。

### 失误2: 步兵 7d191a74 撤离慢一步，多吃25伤

**问题:** R9 为反夺 `cp_east`(4,0) 值得冒险，但 R10 撤离只走到 (3,0)（dist 3），而 R11 收缩到2后 (3,0) 仍在危险区，第11轮边界又吃25（100→75→50）。R10 我方本可让它走满2步直达 (2,0)（dist 2 安全），当时重装攻击消耗的是另一单位的AP，不冲突。

**改进:** 撤离目标按**新半径**规划（radius 2 → 目标 dist ≤ 2），一步到位而不是逐格后撤；收缩边界前最后检查“dist > 新半径”清单。

**预期收益:** 少受25伤（以50血而非75血进入终局，+11军力价值）。

### 失误3: 步兵 90b508b8 在危险区空挂两轮，吃50伤

**问题:** 90b508b8 自 R3 起在 (2,-3)（dist 3）与敌方斥候/游侠交战。R10 我方4个激活点全用于游侠/步兵/重装/撤离，它当轮无行动，却没有利用这轮把它内移到 dist 2（如 (2,-2)/(1,-3)）。R11/R12 边界它在 (2,-3) 连吃50伤（65→40→15）。留在 (2,-3) 确实保留了 R12 击杀敌游侠（位于(2,-2)）的攻击角度，但代价过高——移到 (2,-2) 后仍可由相邻单位补位击杀。

**改进:** 空闲单位优先执行“危险区内移”，把战斗角度让给邻格单位；只有“击杀收益 > 25伤×剩余边界数”时才允许滞留危险区。

**预期收益:** 少受50伤（以65血而非15血进入终局，+22军力价值），且游侠击杀仍可完成。

### 失误4: 终局未提前围杀，29ec1d74 以1血活到裁决

**问题:** 敌方步兵 29ec1d74 终局 1血（R12 我方重装29伤+步兵20伤后仅剩1），但因“每单位每回合仅一次攻击”，R12 我方4个攻击点已用完（杀游侠、杀e7b3357d、压29ec1d74两次），无法当轮补刀。若 R11 把攻击节奏再提前半轮（例如重装不打 e7b3357d 的33伤而提前压 29ec1d74），R12 可完成第3杀，把敌方军力从25再压到~1。

**改进:** 判定“是否可全歼”时按 `存活敌单位数 vs 我方攻击点数×剩余轮数` 提前1-2轮布局；残血必追的对象排序按“移动力+剩余军力价值”而非仅按距离。

**预期收益:** 可能实现 `last_player_standing` 全歼（类似 tg_0075 的 1402:240），或至少再拉开~24军力分差（说明见“与历史对局的对比”）。

## 总结

### 胜利关键因素
1. **9回合8据点经济成型**：收入20→60/轮（对手峰值28），总收入536 vs 272，支撑5次部署292补给，终局军力118 vs 25。
2. **残血重装换敌方满血重装（R7）**：4单位3轮集火 + 6血坦克自杀式斩首，敌方最大肉盾归零，正面再无承伤单位。
3. **两次反夺敌方据点（R7 supply_east、R9 cp_east）**：一进一出16/轮打断敌方收入，部署源压缩到东北角后随R11炮火清零。
4. **炮火时序管理**：R8/R9 完成全部部署（部署源均合法安全），R11 终圈前关键单位撤入 dist 2，敌方2据点被炮火废置、部署冻结。
