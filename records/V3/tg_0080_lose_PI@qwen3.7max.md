## 核心教训

### 致命错误1：选择北路绕行而非中路爆破，步兵比敌方重装晚4轮到达攻击位

本图 `actionsPerTurn=1`，两HQ相距仅4格但被中央障碍物墙阻隔。裁决权重 `enemyHqDamage×20` 极高。我在第3轮部署步兵(cost=45)后，选择了北方通道绕行（需5-6步），而对手 `player_b` 在第3轮部署重装(cost=50)后直接从中路爆破障碍物开路。

**正确做法：** 第3轮也应部署重装（cost=50），走中路爆破路线。重装攻击40远优于步兵30，且拆墙能力使路线更短。从 (2,0) 出发拆 (2,-1)→(1,-1)→(0,-1) 可直达敌 HQ 邻格，比北方通道快2-3轮。

### 致命错误2：侦察兵 (5,-5) 全场闲置11轮，99补给未花完

侦察兵 `6116eb0b` 在 (5,-5) 整局未移动一次。同时最终剩余补给高达 99（`supplies` 权重0，不计裁决分）。

```
第3轮起补给足够部署第二单位时未再部署
第7轮补给 71 → 可部署步兵(45)或侦察兵(38)但未行动
第10轮补给 71 → 可部署重装(50)但未行动

**正确做法：** 第5-6轮补给积累到50+时，用第二个侦察兵或步兵向南方通道推进形成夹击，或部署重装防守 HQ 邻格（如 `(3,-1)`），在敌方重装逼近时进行拦截/对轰。即使不部署第二攻击单位，也应在第7-8轮部署一个单位卡位 `(1,0)` 或 `(2,-1)` 阻挡敌方重装攻击路线。

## 经验教训

### ✅ 做得好的

1. **第2轮侦察兵一步占 cp_2(3,0)** — 锁定 supply+8 收入/轮，经济上与对手持平（行动Merit +2）
2. **第3轮果断部署步兵** — 没有空过蓄力，立即将补给转化为军力（行动Merit +1）
3. **第8-10轮连续3次攻击敌HQ** — 累计82点伤害，行动Merit +6（ceil(27/20)+ceil(27/20)+ceil(28/20) = 2+2+2=6）

### ❌ 致命失误

1. **第3轮选择步兵而非重装** — 步兵攻击30远低于重装40，对轰DPS劣势36 vs 27（差距33%）。且步兵不能拆墙，必须绕行北方通道，比中路爆破多3-4轮
2. **侦察兵 (5,-5) 全场闲置11轮** — 完全浪费一个可行动单位，既不占点也不攻击也不防守，0行动Merit
3. **99补给未花完** — `supplies` 权重0，全部浪费。应在第5-7轮部署第二单位（步兵45或侦察兵38）用于南路夹击或防守HQ邻格
4. **未部署重装防守HQ邻格** — 第7轮看到敌方重装在中央通道推进时，应部署重装至 (2,-1) 或 (3,-1) 卡位拦截，延缓敌方重装攻击我HQ的节奏

### 🔑 核心教训

> **"危险距离是对轰竞速图：重装拆墙 > 步兵绕路，DPS决定生死；99补给不花 = 白送760分HQ伤害差。"**

## 与历史对局的共同教训

1. **重装拆墙竞速是danger-close的核心机制（tg_0037）** — `tg_0037_lose_OMP@longcat2.0.md` 详细总结了"重装比对手晚1拍即崩"。本局完全重复了该教训：双方同轮部署重装/步兵，但我选步兵走北路绕行，对手重装走中路拆墙，结果同时到达但DPS碾压。**tg_0037的教训是"重装先手"，本局教训是"重装 + 拆墙路径 > 步兵 + 绕行路径"。**
2. **口袋中央通道是攻击捷径（tg_0037）** — tg_0037指出中央口袋 (-1,0)/(0,-1)/(0,0)/(1,-1) 是"墙中墙"，一旦破开可直接攻击HQ。本局对手重装正是通过拆 (1,0) blocker 到达我 HQ 邻格。我完全忽视了这条中路通道的威胁。
3. **supplies权重0 = 必须花光补给（tg_0037/tg_0072）** — 多次历史对局证明本图囤补给无裁决分。本局最终剩余99补给是重大资源浪费。
4. **本局新发现：步兵vs重装对轰必输** — 步兵attack 30 - HQ def 4 = 26±3 ≈ 27/刀；重装attack 40 - HQ def 4 = 36±3 ≈ 37/刀。同等回合开火，重装4刀拆完(148)，步兵需5刀(135)。在双方HQ同为120HP的情况下，重装方永远先拆掉对方HQ。**本图步兵只适合占点，不适合对轰HQ。**

- 若敌重装出现在中央通道(0,-1)/(0,0)/(1,-1)附近：
  → 立即用侦察兵或第二单位卡位 (1,0)/(2,-1) 阻挡

  → 部署步兵/侦察兵向南路推进形成夹击
  → 绝不囤补给（supplies权重=0）

终局检查:
- 计算双方HQ剩余HP ÷ 单次伤害 = 存活回合数
- 若我方存活回合 < 敌方存活回合：必须卡位延缓敌方攻击节奏
- 若我方存活回合 ≥ 敌方存活回合：保持攻击节奏即可
```
