## 核心胜利策略

### 1. 扩张期"占完即走"，用侦察兵换时间

**关键决策:** 前3轮不造战斗单位，双步兵+双侦察兵把东侧4个中立点全部落袋。

```text
第1轮 / player_a: 步兵1(5,0)→(3,0) 占 supply_east；侦察兵1部署(4,-1)（seq14/16）
第2轮 / player_a: 侦察兵1(4,-1)→(4,-4) 占 cp_northeast；步兵2(3,-2)→(3,-3) 占 supply_northeast（seq34/35）
第3轮 / player_a: 侦察兵2(4,1)→(0,3) 占 supply_southeast（seq51/54）
```

**为什么有效:**
- 侦察兵38补给、5格机动，是占点性价比之王；4个点对应 8+8+8+4=28/轮 的持续收入。
- 对手走同样路线但多花一轮（第3轮才拿满），我第4轮起就能把全部收入转投游侠/重装。

### 2. 第7轮反夺 `supply_west`：一进一出 16/轮 的经济斩击

**关键决策:** 趁敌步兵1撤离 (-3,0)，步兵1 潜入该格反夺敌补给点。

```text
第7轮 / player_b: 步兵1(-3,0)→(-4,2)（seq125），supply_west 无人看守
第7轮 / player_a: 步兵1(-2,0)→(-3,0)，回合末易主（seq132/134）
```

**为什么有效:**
- 收入事件实证：我 R8 起 control 收入 32→40（+8），敌 44→36（−8）（seq150 vs seq141）。
- 该点同时是敌西侧部署垫，反夺后敌 R9 起只能从 supply_southwest 部署（游侠3/侦察兵，seq168/190），出兵动线被拉远。

### 3. 集火序"重装→游侠→步兵"，永远先打最高价值单位

**关键决策:** 每次交战都把 3-4 个单位的输出倾泻在敌最贵单位上。

```text
第4轮: 游侠33+重装25+步兵18=76伤 → 敌重装1 150→74（seq69-72）
第6轮: 步兵2补刀18 → 敌重装1阵亡（seq110/111）；重装33 → 敌游侠1阵亡（seq113/114）
第10轮: 步兵16+重装26=42 → 敌重装2阵亡（seq195-198）
第12轮: 双重装38+37=75 → 敌游侠3阵亡（seq246-249）
```

**为什么有效:**
- 裁决权重 armyValue×2：击杀92费重装 = 直接 deny 约 92×2=184 分量级（按残血折算也有 50-100）。
- 6次击杀（重×2、游侠×3、步兵×1）全部由集火完成，无一次单打独斗；总输出 692 vs 承受 576，净输出 +116。

### 4. 炮火当武器：把敌重装2困在危险区吃两轮炮

**关键决策:** 第7-9轮围而不急于强攻，敌重装2被迫在 (-3,-1)→(-4,1) 的危险区机动。

```text

第10轮边界: 敌重装2(-4,1) 仍在危险区 → 再炮击25（seq181，39hp）
第10轮 / player_a: 步兵16+重装26=42 ≥ 39 → 收割（seq195-198）
```

**为什么有效:**
- 50 点免费伤害 = 省掉约两个单位的输出回合；敌重装2从满血到死只吃了我们 42 点攻击。
- 对手的正确做法是 R9 直接退到 (-3,0)/(-2,1)（距3安全格），但他选择贴着我步兵1对峙，被炮火连咬两轮。

### 5. 终局保军：残血全撤终圈，输出只给双重装

**关键决策:** R11 收缩到半径2当轮，用 2AP 把 11hp/12hp 的两个步兵撤入安全区，只留重装在外线输出。

## 失误与改进

### 失误1: 第7轮攻击"尸体"，3AP 打水漂

**问题:** 敌重装1已在 R6 阵亡，但我的回合规划沿用了旧状态里的单位列表；取目标 ID 时查询未过滤 `alive`，取到死去的重装1 ID，连续 3 次攻击全部返回 `target_not_found`（重装的移动+攻击、两步兵的攻击全部落空）。整轮 4AP 只有部署步兵有效，浪费一轮对敌重装2的集火（约 60 伤），敌重装2因此多活一轮并多输出一轮。
**改进:** 每次攻击前必须：(a) 行动前即时 `GET /api/games/:id` 刷新状态；(b) 取目标 ID 时强制 `alive==true && hp>0` 过滤；(c) 同一目标被首个攻击击杀后立即改选目标而非继续提交。
**预期收益:** 本局可提前一轮击杀敌重装2（约挽回 40-60 军力分与 20-30 actionScore）。

### 失误2: 六边形距离误判连犯三次（tg_0040/tg_0080 教训复发）

**问题:** (a) R1 重装 (4,1)→(2,0) 提交失败——实际距离3超移动2；(b) R3 以为重装 (1,1) 与 (0,0) 相邻（实际距离2），攻击报 `out of range`，多花1AP补走位；(c) R4 部署游侠初选 (3,1)，临提交前才发现距敌重装4格打不到，改 (3,0) 才成立。公式是 `max(|dq|,|dr|,|dq+dr|)`，我多次只算了前两项。
**改进:** 每次移动/攻击/部署前用完整三项公式验算并写下来；对"相邻"永远显式验证距离==1。
**预期收益:** 本局三次误判共损失约 1.5AP+一轮集火节奏；tg_0040 曾因此直接输棋，这是跨局重复度最高的错误。

### 失误3: 第6轮游侠1暴露在双游侠射界内被秒杀

**问题:** R5 把游侠1推进到 (0,0) 中心，回合结束时距敌游侠1(-2,-1) 3格、距敌重装1(-1,-1) 1格；R6 敌以游侠2 40伤+游侠1 42伤（seq103/104）直接秒杀满血游侠。远程单位（防御3）绝不能贴着敌集群过对手回合。
**改进:** 游侠/远程单位回合结束时必须自查：是否在任一敌方攻击单位的 range 内？若是，宁退一格。
**预期收益:** 保住 72 价值单位，中盘军力曲线更平滑。

### 失误4: 炮火规避纪律仍不彻底（承伤190，约85可避免）

**问题:** 我方炮火承伤合计 190（R9:75、R11:100、R12:15，侦察兵1阵亡）：(a) R7 部署步兵选 (3,1)（距4），R9 边界白吃25——(3,0)/(2,1) 都是安全格；(b) 侦察兵1自 R2 起长驻 cp_northeast(4,-4)（距4），直到 R9 才动，连吃 25+25+15 阵亡；(c) R11 两个步兵是先吃炮（各25）后才撤离。tg_0079 复盘已明确批评"单位驻守据点吃炮击、约125-150伤可避免"。
**改进:** 部署格必须选在当前与下两轮收缩后都安全的半径内；预警事件（`artillery_warning`）出现当轮即清点距边界≤1的单位并预撤离。
**预期收益:** 本局可省约 85 承伤（=约 40-50 军力分），侦察兵1可存活。

## 总结

### 胜利关键因素
1. **集火纪律**：6次击杀全部由多单位同轮集火完成，优先序"重装→游侠→步兵"从未动摇，总输出 692 vs 承受 576。
2. **经济反夺**：R7 反夺 supply_west 造成 16/轮 双向 swing，五轮 +80 补给直接支撑 R10 的 92 费重装，是军力曲线的拐点。
3. **炮火借刀**：敌重装2被围困在危险区连吃两轮炮（50伤）后收割；我方所有大单位（双重装、游侠）全程零炮伤。
4. **终局保军**：R11-R12 残血单位全部撤入终圈消耗敌方 AP，双重装满状态完成最后一击，军力差定格 120:24。

### 核心战术原则
> **“占点用侦察兵，打仗认最大：每轮输出砸最贵的敌人，每轮结束查最脆的自己；炮火是第三个玩家，把敌人逼进它的射程。”**

### 一句话总结
**在炮火禁区歼灭局中，我作为后手以侦察兵速占东翼4点、第7轮反夺敌补给点扭断经济，用"重装→游侠→步兵"的集火序六斩敌核心，并借炮火困杀敌二代重装，最终以军力120:24、裁决830:538取胜——但攻击尸体浪费整轮与190点炮伤中的85点证明：提交前验算距离/存活/半径，仍是下一局的第一课。**
