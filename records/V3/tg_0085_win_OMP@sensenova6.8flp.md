## 核心胜利策略

### 1. 先手稳健占点：R1-R3 连续抢3个补给点

**关键决策:** 第1轮先手，用3 AP 移动 + 1 AP 部署，快速占领西线两个补给点；第2轮继续抢西南补给点；第3轮用侦察兵高速抢下西北补给点。

```text
第1轮 / player_b: 步兵1(-5,0)→(-3,0) 占 supply_west；步兵2(-5,1)→(-3,3) 占 supply_southwest；部署侦察兵@(-5,0)
第2轮 / player_b: 步兵2(-3,1)→(-3,3) 占 supply_southwest；部署侦察兵@(-5,0)
第3轮 / player_b: 侦察兵(-5,0)→(0,-3) 占 supply_northwest
R3 末: cp_west + supply_west + supply_southwest + supply_northwest = 4控点，收入 36/轮
```

**为什么有效:**
- 敌方第1轮仅推进未占点，R2 起才陆续占4个东线控点。我 R3 末即建立 4控点、36/轮 vs 敌4控点、32/轮 的经济均势。
- 侦察兵38费高速（moveRange=5），能在1个AP内从最外圈冲到中心补给点，是抢点的最佳选择。
- 经济均势 + 先手行动顺序优势，使我方在开局4轮内保持节奏主动权。

### 2. 重装压血战术：7轮持续攻击同一敌重装，从150打到0

**关键决策:** 自第4轮起，我方重装(cd4edf96)每轮都对敌方重装(23e3a632)进行攻击，持续7轮共造成149伤，最终在第10轮击杀。

```text
R4: 重装(0,0)→敌重装(1,0) 24伤(150→126)
R5: 重装(0,0)→敌重装(1,0) 22伤(126→104)
R6: 重装(0,0)→敌重装(1,0) 22伤(104→82)
R7: 重装(0,0)→敌重装(1,0) 26伤(82→56)
R8: 重装(0,0)→敌重装(1,0) 25伤(56→31)
R9: 重装(1,-1)→敌重装(2,-1) 28伤(31→3)
R10: 重装(0,-1)→敌重装(0,0) 28伤(3→0) ✅击杀
累计：149伤（我方7次攻击），敌重装150HP归零
```

**为什么有效:**
- 敌重装是唯一高价值单位（军力92），击杀后敌方全军仅剩步兵和侦察兵，军力价值大幅缩水。
- 每次攻击都发生在敌重装反击我之前或之后紧邻，形成"互相输出"的拉锯，我方重装从150→73 HP，承受了99伤，但价值交换比 149:99 = 1.5:1 明显占优。
- 击杀时刻（R10）距终局仅2轮，敌方失去了最后的重装威胁。

### 3. 侦察兵海战术：6侦察兵部署，军力价值持续压制

**关键决策:** 除1个步兵外，全部7次部署选择侦察兵（38费），总费用228补给，构建侦察兵海。

```text
R1: 部署侦察兵@(-5,0)  seq11  cost=38
R2: 部署侦察兵@(-5,0)  seq39  cost=38
R4: 部署侦察兵@(-4,1)  seq57  cost=38
R5: 部署侦察兵@(-4,-1) seq70  cost=38
R6: 部署步兵@(-5,1)    seq86  cost=45
R7: 部署侦察兵@(-4,1)  seq105 cost=38
R8: 部署侦察兵@(-3,-1) seq119 cost=38
总部署: 6侦察 × 38 + 1步兵 × 45 = 228 + 45 = 273 补给
```

**为什么有效:**
- 敌方部署6单位（1侦察+5步兵=263费），我方部署7单位（6侦察+1步兵=273费），多1单位。
- 最终裁决军力价值 209 × 2 = 418 vs 敌 162 × 2 = 324，差 +94 分，是胜负的关键杠杆。
- 侦察兵65HP虽低，但38费便宜，可以大量部署保持数量优势。即使R11炮火损失3个侦察兵，仍有4个存活 + 重装 + 2步兵 = 7单位。

### 4. 集火纪律：重装配合作战，优先压重装、后转步兵

**关键决策:** 前7轮全部集火敌重装，击杀后（R10）转向攻击敌方步兵，终局（R12）对敌剩余步兵全面输出。

```text

R11: 重装(1,0) 攻击敌步兵(1,1) 28伤；侦察兵(1,-1) 攻击敌侦察(1,-2) 14伤；侦察兵(0,1) 攻击敌步兵(1,1) 5伤
R12: 重装(1,0) 攻击敌步兵(2,0) 27伤
```

**为什么有效:**
- 重装击杀后，我方 actionScore 从 R9的230 → R12的320（+90），主要靠攻击 merit（每次攻击贡献 ceil(dmg/20) × effectiveActions 10）。
- 我方共11次攻击，累计伤害249，actionMerit贡献19；敌方7次攻击，累计伤害146，actionMerit贡献10。actionScore 320:220，差100分。
- 重装击杀（seq160）是最高价值攻击事件，直接改变了终局军力天平。

## 失误与改进

### 失误1: R8预警当轮未撤 dist≥4 的单位，R9-R11连续吃炮导致3单位阵亡

**问题:** R8的 `artillery_warning`（seq115）已将 dist=4 的格子列入 warningCells，但 R8 我4AP用于重装攻击（seq118）和部署侦察兵（seq119），未把步兵(-4,0)和侦察兵(-4,1)内移。R9边界步兵(-4,0)吃25(75→50)，R10边界再吃25(50→25)，R11边界再吃25(25→0) 阵亡。侦察(-4,1)从65→40→15→0 阵亡。侦察(-3,-1)从65→40→25→0 阵亡。总计我方 3单位因炮火阵亡（25+25+25+15+15+25+25+25=175炮伤 + 3单位死亡）。

与 tg_0084（同地图）的"收缩撤离纪律"教训一致——连续两局犯同一错误。

**改进:** 收到 `artillery_warning` 的当轮，把 dist ≥ 新 safeRadius+1 的格子列入"必撤清单"，优先于一切攻击和部署；收缩边界前逐单位核对 `dangerCells`。如果无法在当轮撤离，也应将 dist=4 的单位移至 dist≤3。

**预期收益:** 省 175 炮伤 ≈ 87 军力分；更重要的是保住3单位（2侦察65×2=130军力 + 1步兵100军力=230军力≈460裁决分）。若该3单位存活，终局总分可达约 1198，分差从 194 扩大到约 650。

### 失误2: 重装追击时移动优先级让位于部署，R9-R10损失1轮输出

**问题:** R9 重装在(0,0)，敌重装在(2,-1)距离3。我方重装移动了1格到(1,-1)然后攻击28伤(31→3)，但移动2格可以直接到(1,-1)位置攻击（实际moveRange=2，从(0,0)可以移动2格到达(1,-1)）。此处判断无误但R9结束时敌重装仅3HP，R10边界敌重装在(0,0)距我方重装(1,-1)仅距离1——如果R9重装有2AP，可以直接攻击2次，可能提前击杀（28+28=56 ≥ 3HP），省掉R10的追击轮次。

**改进:** 当目标HP低于一次攻击的下限（重装38攻×1浮动33）时，优先用重装连续攻击至击杀，而非浪费AP在移动或部署上。

**预期收益:** 提前击杀1轮意味着重装在R10可以攻击其他敌单位（如敌步兵8539e6bf），增加军力损失和actionScore。

### 失误3: R11-R12终局无法部署，148补给无法转化为军力

**问题:** R10结束时我方有36补给，R11结束时仍有36补给（未部署），R12结束时终值144补给。本局最后2轮（R11-R12）safeRadius=2，所有控制点（cp_west dist=4, supply_west dist=3, supply_northwest dist=3, supply_southwest dist=3）全部处于危险区或边缘，无法部署。

**改进:** 在 R10（最后一个 cp_west 仍处于 dist=4 预警区内但尚未入危险区的窗口）部署步兵，哪怕少一次攻击。实际上R10我方部署了2次（步兵942fa9a4 seq86, 侦察2a3c892e seq105），均被炮火击杀——应在更早的R9之前完成关键部署。

**预期收益:** 多1步兵（45军力≈90裁决分）；若成功存活到终局，可进一步拉大分差。

**结论:**
1. **"收缩撤离纪律"教训第三次复发**：tg_0082/0083/0084 已多次指出"预警当轮必撤"，本局 R8 预警仍未撤 dist=4 的步兵和侦察兵，导致 R9-R11 累计175炮伤 + 3单位阵亡。连续四局犯同一错误，必须在下一局强制执行预警撤离检查。
2. **先手优势确认**：与 tg_0084（后手）相比，本局先手使 R1 我方即可行动，抢占了 supply_west/supply_southwest。但先手不等于碾压——敌方 R2-R3 迅速追平经济后，胜负仍取决于后续战术执行。
3. **侦察兵海战术的验证**：6侦察兵（228费）+ 1步兵（45费）vs 敌 1侦察+5步兵（263费）。我方多1单位，军力209 vs 敌162。侦察兵便宜但脆弱，R11炮火损失2个，若换步兵可能存活率更高。
4. **重装压血战术的成功**：7轮持续集火同一敌重装，175伤致死。这是本局最关键的操作——若未击杀，终局军力差可能不足以胜出。

## 总结

### 胜利关键因素
1. **重装持续压制**：7轮集火敌重装（175伤致死），击杀后敌方失去核心战斗力
2. **侦察兵海战术**：6侦察兵快速占点+数量优势，军力价值持续领先
3. **先手节奏把控**：R1-R3快速占4控点建立经济均势，后续每轮保持进攻节奏

### 核心战术原则
> **"重装压重装，侦察兵抢点，预警必撤"**

### 一句话总结
**先手抢4点建立经济均势，重装7轮集火击杀敌重装，侦察兵海数量压制，但炮火撤离纪律再次失守导致3单位阵亡——最终以738:544裁决胜利，但教训必须吸取。**
