## 核心胜利策略

### 1. 重装兵爆破开路 — 突破空心墙

**关键决策:** 利用重装兵（heavy）的爆破能力，逐个拆除阻隔双方HQ的障碍墙，开辟直达敌方HQ的通道。

```text
第4轮 / player_b: 从HQ(2,0)部署重装兵至(2,1)，花费50补给
第5轮 / player_b: 爆破(1,1)障碍→平地；重装兵(2,1)→(1,1)
第6轮 / player_b: 重装兵(1,1)→(0,0)
第7轮 / player_b: 爆破(-1,0)障碍→平地
第8轮 / player_b: 重装兵(0,0)→(-1,0)，攻击HQ造成34伤害
```

**为什么有效:**
- 地图`danger-close`的障碍墙完全阻隔了双方HQ（直线距离仅4格，但被障碍物封锁），不爆破无法接近。
- 重装兵是唯一能爆破的单位（`canCapture=false`，但可`demolish`），且HP 150、攻击40、防御13，在接近HQ过程中能承受对手火力。
- 对手`player_a`在前3轮专注于抢占cp_1，直到第4轮才部署步兵，且之后没有部署重装兵或游侠等高威胁单位，无法拦截我的重装兵。

### 2. 抢占经济点 — 支撑持续作战

**关键决策:** 第2轮抢占cp_2，获得每轮+8补给收入（基础6+cp_2 8=14），确保后续部署和维持重装兵的经济基础。

```text
第1轮 / player_b: 侦察兵(5,-4)→(3,-1)
第2轮 / player_b: 侦察兵(3,-1)→(3,0)，占领cp_2
第3轮 / player_b: 收入14（基础6 + cp_2补给8）
```

**为什么有效:**
- 初始补给仅20，重装兵花费50，必须依靠cp_2的持续收入才能在第4轮部署。
- 对手同样占领了cp_1，但其部署的步兵（45补给）性价比远低于我的重装兵（50补给换150HP/40攻击）。
- `supplies`权重为0，多余补给不产生裁决分，因此在确保关键部署后无需囤积。

### 3. 每回合行动点效率最大化

**关键决策:** `actionsPerTurn=1`，但同一单位激活后的后续合法动作不重复扣行动点。利用此规则，在单回合内完成"爆破+移动"（第5轮）和"移动+攻击"（第8轮）。

```text
第5轮 / player_b: 爆破(1,1) [消耗1AP] + 移动(2,1)→(1,1) [免费，同单位]
第8轮 / player_b: 移动(0,0)→(-1,0) [消耗1AP] + 攻击HQ [免费，同单位]
```

**为什么有效:**
- 如果每回合只能做1个动作，爆破后需要等下一回合才能移动，会多花1轮。
- 同单位后续动作免费规则允许在1个席位回合内完成多个动作，大幅压缩推进时间。

### 4. 集中火力攻 HQ — 裁决权重最大化

**关键决策:** 裁决权重中`enemyHqDamage=20`（最高），HQ伤害是胜负核心。重装兵每次攻击造成34-38伤害，4轮攻击总计120伤害，直接摧毁HQ。

```text
第8轮 / player_b: 攻击HQ，伤害34，HQ 120→86
第9轮 / player_b: 攻击HQ，伤害38，HQ 86→48
第10轮 / player_b: 攻击HQ，伤害35，HQ 48→13
第11轮 / player_b: 攻击HQ，伤害34（实际13），HQ 13→0，获胜
```

**为什么有效:**
- `last_player_standing`规则下，摧毁HQ直接获胜，无需等待裁决。
- 对手`player_a`在HQ受攻击期间没有采取任何有效防御（未部署防御单位、未反击我的重装兵），让我无压力输出。

## 失误与改进

### 失误1: 前两轮的侦察兵移动路线不够优化

**问题:** 第1轮将侦察兵从(5,-4)移动到(3,-1)，第2轮再从(3,-1)移动到(3,0)占领cp_2。如果第1轮直接移动到(3,0)，可以提前1轮占领cp_2，第2轮即可开始享受cp_2收入。

**改进:** 侦察兵初始位置(5,-4)到cp_2(3,0)的曼哈顿距离为max(|5-3|, |-4-0|, |(-9)-(-3)|)=max(2,4,6)=6，但实际移动路径经过(4,-3)→(3,-2)→(3,-1)→(3,0)共4步。由于`moveRange=3`，第1轮可直接从(5,-4)移动到(3,-1)（距离3），第2轮再移动到(3,0)。如果规划更优路径，第1轮可移动到(3,-2)（距离3），第2轮直接到(3,0)，节省1轮。

**预期收益:** 提前1轮占领cp_2，第3轮即可获得cp_2收入（+8补给），比实际早1轮，可能影响第4轮部署重装兵的时机。

### 失误2: 未在HQ受攻击期间部署防御单位

**问题:** 第8-11轮HQ持续受攻击期间，我方没有部署任何防御单位（如步兵或侦察兵）保护HQ。虽然对手没有反击，但如果对手有类似策略，我方HQ可能受到威胁。

**改进:** 在重装兵推进的同时，应保留1个侦察兵或步兵在HQ附近作为防御。或者在第5轮之后，用剩余补给部署1个步兵在HQ相邻格。

**预期收益:** 多一层HQ保护，防止对手意外反击导致HQ受损（`ownHqHp`权重为1，HQ受损会直接影响裁决分）。

## 总结

### 胜利关键因素

1. **重装兵爆破开路** — 利用heavy的demolish能力逐墙推进，是danger-close地图的唯一突破手段。
2. **cp_2经济支撑** — 抢占补给据点确保重装兵部署和持续作战的经济基础。
3. **同单位多动作免费** — 在1个席位回合内完成爆破+移动、移动+攻击，大幅压缩时间。
4. **对手无有效防御** — 对手未部署反重装兵单位或尝试拦截，让我方无压力输出HQ。

### 核心战术原则

> **“抢经济点、爆破开路、重装兵直击HQ—— danger-close 标准三步走”**

**利用重装兵的爆破能力在5轮内打通障碍墙，随后4轮持续输出HQ伤害，在第11轮以`last_player_standing`获胜，验证了danger-close地图上"爆破+攻城"策略的有效性。
