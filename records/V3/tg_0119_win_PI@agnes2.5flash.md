## 核心胜利策略

### 1. 双线同时抢点：上下路线各占2据点

**关键决策:** 第1轮即把5个单位分派到上路（cp_nw方向）和下路（cp_sw方向），不等对手反应。

```text
第1轮 / player_a: scout①@(-6,-1)、scout②@(-7,-1)、inf①@(-6,0) → 上路推进
第1轮 / player_a: inf②@(-7,1)、scout③@(-8,0) → 下路推进
第2轮 / player_a: scout① 占cp_nw(-2,-4)（seq23）✅
第3轮 / player_a: inf② 占cp_sw(-6,4)（seq40）✅
```

**为什么有效:** 中路被blocker(−2~2,0)和water(−1~2,−1/1)完全封锁，双方被迫走上下两路。先占cp_nw（+12/轮）和cp_sw（+8/轮+部署折扣）后，我方从R3起收入30/轮 vs 对手R3起仅22/轮。更重要的是cp_sw提供-8部署折扣，使后续步兵部署成本从45→37，侦察兵从38→30。

对比 tg_0084（同模型同一对手，artillery-zone 歼灭模式）：该局我方只占了2个据点，军力只有113 vs 对手265。本局通过双线抢点，最终4据点 vs 对手2据点，裁决cp得分 360 vs 180，净胜180分。

### 2. 持续削皮+补刀：击杀敌方主力侦察兵

**关键决策:** 自R4起持续攻击敌方前线scout（`15b3fc68`），累计8次攻击，最终R10补刀击杀。

```text
R4  seq55: 9伤（56→45）
R5  seq74: 11伤（54→43）
R6  seq88: 9伤（55→46）
R7  seq105: 13伤（52→39）
R8  seq123: 23伤（39→16）
R9  seq136: 29伤（16→10）← 削至濒死
R10 seq152: 10伤→0 击杀（seq153）← 补刀
```

**为什么有效:**
- 8次攻击 merit = ceil(9/20)+ceil(11/20)+ceil(9/20)+ceil(13/20)+ceil(23/20)+ceil(29/20)+ceil(10/20) = 1+1+1+1+2+2+1 = **10 merit** → actionScore +20（×effectiveActions=2 = +20分）
- 击杀deny对方38 armyValue（scout成本38），并消除其对cp_nw守军的威胁
- 敌方被迫用cp_nc维修（每次+10HP）续命，浪费了其AP

### 3. 利用forward_base折扣高效扩军

**关键决策:** 占领cp_sw后，优先从此处部署低费单位，建立南线防线。

```text
R4  seq54: inf③@(-5,4) cost 37（45-8折扣）
R5  seq72: scout④@(-6,3) cost 30（38-8折扣）
R7  seq104: scout⑦@(-6,5) cost 30（折扣）
```

**为什么有效:** 3次折扣部署节省 8+8+8 = 24补给，相当于额外1/3个步兵的成本。这些单位在R15结束时大多存活，贡献了总计约 114 armyValue。

### 4. cp_nc争夺：中期突破

**关键决策:** R11集中兵力夺cp_nc，这是地图中央唯一的repair点，控住它等于切断敌方北线补给链。

```text
R11 seq180: inf①(1,-4)→(2,-4)
R11 seq185: 占领cp_nc（前一手段player_b控制）✅
```

**为什么有效:** 夺cp_nc后收入从30升至38/轮（+8），同时剥夺敌方cp_nc的+8收入。最终4据点收入46/轮 vs 对手2据点30/轮，差距16/轮×5轮=80补给优势。

## 失误与改进

### 失误1: 前线侦察兵反复被对手反击，未能及时撤离

**问题:** scout①（`1ba63398`）自R3占cp_nw后，R5-R8连续4轮被敌方scout反击（累计承受44伤：11+10+13+11），始终未撤离到安全距离。

**改进:** 占领据点后，若邻近有敌方射程内单位，应当轮移动至据点安全格（如cp_nw的(-3,-4)或(-2,-5)）。持续暴露于敌方scout（moveRange=5）射程内是低效决策。

**预期收益:** 减少44HP损伤 ≈ 保存22%armyValue（≈8分）；此外役单位若存活至终局可额外贡献≈15分armyValue。

### 失误2: 未尝试抢占cp_se（东南前线基地）

**问题:** cp_se是forward_base类型，与cp_sw对称，我方R4即已具备占领条件（inf①在(-2,-1)，距离cp_se仅5格），但从未派兵前往。

**改进:** 应在R5-R6期间派高moveRange单位（如scout moveRange=5）尝试抢占cp_se。即使失败也能迫使对手分兵防守。

**预期收益:** 5据点→cp得分450（+90分），收入+8/轮。但需评估风险：cp_se邻近敌方ranger（attackRange=3），可能遭远程攻击。
