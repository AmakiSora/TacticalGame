## 核心胜利策略

### 1. 先寻路确认唯一攻城走廊，抢先占领

**关键决策:** 用 BFS 在开局确认中央被墙封死、唯一通路是南侧边缘 `(-2,-1)←(-1,-2)←(0,-3)←(1,-4)←(2,-5)`，敌HQ攻击格 `(-2,-1)` 距我起始侦察兵仅 7 格。

```text
第1轮 / player_b: 892441e8 (5,-5)→(2,-5)            // 进入走廊
第2轮 / player_b: 892441e8 (2,-5)→(0,-4)            // 推进
第3轮 / player_b: 892441e8 (0,-4)→(-2,-1) 贴脸敌HQ  // 3回合抵达攻击格
第3轮 / player_a: 仍在本方左侧防守，未封锁南侧      // 走廊未被切断
```

**为什么有效:**
- 地图说明文字称“唯一的突破口是重装兵的爆破”，但实际 BFS 证明南/北边缘本就开路——**不盲信 flavor text，以寻路为准**，省下重装兵的造价与 2 格慢速。
- 侦察兵 3 格/回合，3 回合即贴脸，比敌方任何单位更早接触 HQ。

### 2. 移动后免费攻击（move+attack 同回合）

**关键决策:** 凡单位移动到敌HQ攻击格的同一回合，立即追加一次攻击（`hasMoved=True, hasActed=False` 已证实该规则）。

```text
第3轮 / player_b: 892441e8 移动至(-2,-1) → 同回合攻击 HQ dmg13
第10轮 / player_b: d25b9505 移动至(-2,-1) → 同回合攻击 HQ dmg29
```

**为什么有效:**
- 每个“抵达”回合都能开火，把 `enemyHqDamage×20` 的收益最大化，不浪费抵达回合的行动点。

### 3. 廉价侦察兵榨首血，耐久步兵接力收尾

**关键决策:** 先派 38 补给的侦察兵贴脸榨血至阵亡，再派 45 补给的步兵接力完成斩首。

```text
第3-6轮 / player_b: 892441e8 四刀 HQ：13+9+12+12=46 伤害，阵亡前已建绝对领先（ROI≈1.2 伤害/补给）
第7轮 / player_b: 部署 d25b9505(步兵) 于(3,-1)
第10-12轮 / player_b: d25b9505 三刀 HQ：29+28+27=84 伤害，终结
```

**为什么有效:**
- 侦察兵以最小代价先手建立 ×20 计分碾压；步兵高 HP（100）扛住敌反制，确保抵达并存活到终斩。

### 4. 无视据点，专注 HQ —— 修正历史“据点决定论”

**关键决策:** 全程 0 个据点，所有行动点用于攻城；敌方占 `cp_1` 拿 +30 分 +8 收入，仍被 HQ 伤害碾压。

```text
敌方: 第2轮占 cp_1 → 每回合+14补给、终局 controlPoints=1(+30分)
我方: 0 CP，但 HQ伤害 120×20=2400 分 >> 敌方全部得分 221
```

**为什么有效:**
- 本局裁决权重 `enemyHqDamage=20`、`controlPoint=30` 但仅 2 个 CP（单点上限 30 分），而 HQ 伤害可无限堆叠；当 HQ 权重压倒性时，经济点相对失效。
- 历史 WB@hy3 复盘（tg_0045「先抢多点锁经济，HQ 放血锦上添花」、tg_0031「占点先于杀敌」）的“据点决定论”**在本图被本局配置否定**——原则必须按本局 `adjudicationWeights` 重写，不能跨图套用。

### 5. 先手优势（turnOrder 首位）

**关键决策:** 本局 `firstPlayer=player_b` 且 `turnOrder=[player_b, player_a]`，我每个整轮先动。

```text
第12轮 / player_b 先手: 攻击 HQ 17→0，敌总部摧毁 → 敌无反制窗口
```

**为什么有效:**
- 先手保证 R12 终斩由我完成；也让我 R3 比敌步兵反制早一整轮贴脸开火。

## 失误与改进

### 失误1: 第二侦察兵 d664d67b 全程闲置

**问题:** 初始侦察兵 `d664d67b` 始终停留在 (5,-4)，从未投入进攻或争夺 `cp_2`；终局它仍存活（贡献 armyValue 38），但 0 HQ 伤害、0 据点贡献。
**改进:** 第2轮起令其沿北侧/东侧迂回牵制，或作为第二攻城手同步压向 `(-2,-1)`，形成双线放血。
**预期收益:** 多一条 HQ 攻击线（提前 1-2 轮结束），或至少争夺 `cp_2` 拿 +30 分与 +8 收入；即便本局非必需，面对激进对手可显著缩短战程。

### 失误2: 接力步兵部署偏晚，行军 3 轮才贴脸

**问题:** 第7轮才部署步兵，第8-10轮纯行军，第10轮才贴脸开火——中间 3 轮（R7-R9）我方 0 HQ 伤害输出。若对手用重装兵爆破南侧走廊或集火 my infantry，可能被拖延甚至翻盘。
**改进:** 更早就规划“接力梯队”的路线与到达回合，确保 R9 前贴脸；本局因敌被动未受影响，但面对积极对手需更早（R5-R6）部署第二梯队并预铺路线。
**预期收益:** 缩短无输出空窗，降低被对手中路封堵/集火的风险。

## 总结

### 胜利关键因素
1. 开局 BFS 确认唯一攻城走廊并抢先占领，不盲信“需重装兵爆破”的地图说明。
2. 利用“移动后免费攻击”规则，把 `enemyHqDamage×20` 每抵达回合都变现。
3. 廉价侦察兵榨首血 + 耐久步兵接力收尾，成本极低、输出极高。
4. 先手轮次（turnOrder 首位）保证 R12 终斩由我完成，敌无反制窗口。

### 核心战术原则
> **“墙图先用寻路确认唯一通路，贴脸 HQ 即开火；当 HQ 伤害权重压倒据点时，放弃经济点专攻城。”**

### 一句话总结
**“在偏重 HQ 伤害的墙图，先手侦察兵抢通南侧走廊、贴脸即放血，耐久步兵接力三刀斩首，据点经济皆可弃。”**
