## 实际做法 vs 正确做法

### 致命错误 1：两个 ranger 连续部署在同一个暴露格 (-2,0)，被对手用"偷来的据点通道"原样集火两次

**实际：** R4 从 `supply_west` 部署 ranger `37893094` 到 (-2,0)（距敌 ranger 2 格、距敌双步兵 3 格——移动+射程即可围攻），对手 R4 部署 ranger 后三连击 95 伤击杀（seq75→77）。R6 我又从同一 `supply_west` 部署第二个 ranger `17362f29` 到**同一格 (-2,0)**（seq107），对手再次三连击 99 伤击杀（seq119）。144 补给 + 2 轮满 AP 部署，只换掉对手 1 个 ranger（72）。
**触发条件：** 己方 ranger 阵亡后，未更换部署格/出发通道即补同款；且 (-2,0) 这个格同时被判定为"能打到人"却未验证"能被几个人打到"。
**正确做法：** ① ranger 落点必须过"被围攻检查"——落点同时处于 ≥2 个敌方单位"移动+射程"覆盖圈内时换格（安全落点如 (-3,1)/(-1,3)，距敌阵 ≥4）；② ranger 阵亡后当轮先不补，用步兵线稳住，下一轮从更靠内的 pad（`supply_southeast` (0,3) 或 `cp_west`）出发；③ 早该把"打断对手 ranger 通道"列为战略目标——`supply_northwest` R3 被偷后，对手 R4/R5 两次从它部署（ranger、inf），抢回或盯死这个点等于掐断对手远程线（tg_0144 的同图铁律："ranger 的关键不是早出而是打不断的补充通道"，本局我连丢两次 ranger 正是该铁律的反面教材）。
**预期收益：** 省 72 补给 + 2 次部署 AP；更关键是把这两个 ranger 的 72×2 军力留在终局 ≈ **+144 军力分（×2 权重）**。

### 致命错误 2：R10 warning 后两个 d3 单位未撤离，白吃 50 点炮火伤害

**实际：** R10 warning（seq181）明确下一档 safeRadius=2，(1,2) 与 (-2,-1) 两个 infantry 在 d3 环上。我把 4 个 AP 全部用于攻击（换来敌 2 击杀，本身正确），但没有给这两个单位各移 1 格（(1,2)→(1,1)、(-2,-1)→(-1,-1)，都是安全空格）。R11 开局两者各吃 25（seq204/205）：`fb02cc97` 100→75（此后又被三连击压到 9）、`752da988` 76→51。
**触发条件：** `artillery_warning` 当轮，存在 rad > 下一档 safeRadius 的己方单位，且该单位当轮还有未用激活。
**正确做法：** tg_0144 立的量化红线原样适用——**预警当轮，凡 rad > 下一档 safeRadius 的单位，除"当轮能靠一次激活撤回"外一律内移**。本局两单位各移 1 格即达标，代价仅是放弃当轮 2 次攻击（约 44 期望伤害 ≈ 4 功勋 = 40 分）。**权衡：50 点炮火伤 ≈ 22 军力价值（×2 = 44 分）+ 把 `fb02cc97` 从 100 压到 75 间接导致其 R11 后只剩 9HP；省下的是 2 次残血击杀的铺垫。结论：仍应撤——因为那 2 个被杀的敌 inf（34HP/15HP）本就已被前几轮打到残血，晚一轮收掉无实质损失，而炮火伤是净亏。**
**预期收益：** 终局军力 +22（×2 = +44 分）且 `fb02cc97` 不必以 9HP 残局。

### 致命错误 3：占点单位"占完即走"，两个据点被零成本偷走

**预期收益：** 收入 40→44+ 持续；更重要的是 `supply_northwest` 不丢则对手 ranger 通道消失，致命错误①的两场集火根本不会发生。

### 致命错误 4：终局 141 补给无法转化——"钱要趁 ring 还没吃掉据点时花掉"

## 总结

### 做得好的
1. **开局三轮抢点干净**：R1-R3 连下 supply_west/supply_northwest/supply_southwest/supply_southeast/cp_northwest/cp_southeast 六个点，R5 收入峰值 44/轮（6 据点），前期经济碾压对手（44 vs 36）。
2. **集火收残血纪律良好**：5 次击杀中 3 次是残血收割（R5/R7/R10）、2 次双步兵合击（R10/R11），没有把伤害摊薄到多人头上。
3. **炮火总承伤 50 为同图三局最低**（tg_0136 100、tg_0144 125），且全程 0 炮火直接死亡；R11-R12 全部单位收进 rad2，终局边界 0 承伤。
4. **账本全程可闭合**：补给两册与 `game_over` 精确一致（45+420−324=141、45+412−373=84），功勋构成逐事件复核（6+12+40=58），并发现了"先手方 R1 无 income"的规则细节。

### 下次改进
1. **触发条件：ranger 阵亡 → 下一轮补 ranger 前必须换落点，且落点不得同时处于 ≥2 个敌方单位"移动+射程"覆盖圈。** 本局 (-2,0) 连死两次，144 补给换 72。
2. **触发条件：`artillery_warning` 当轮 → 机械清点 rad > 下一档 safeRadius 的己方单位，能撤的一律内移（哪怕少 1 次攻击）。** 本局 50 点净亏。
3. **触发条件：任何 `canCapture` 单位离开据点 → 该点不得连续 1 个整轮空置；若空置且该点是对手 3 移动内的通道，优先夺回/盯防。** 本局 supply_northwest 失守引发 ranger 通道+两次集火+12 收入/轮的连锁亏损。
4. **触发条件：safeRadius ≤ 3（本图 R9 起）且补给 ≥ 45 → 每轮固定留 1 AP 部署。** R11 起所有 CP 进危险区、部署锁死，晚花 = 花不掉。
5. **触发条件：任何 move/attack/deploy 调用前 → 邻居表 + `max(|dq|,|dr|,|dq+dr|)` 机核距离；轮末先穷举未激活单位可达目标再 `/end-turn`。** 本局 6 次 API 拒绝 + 2 次 AP 空转全部源于此。

> **核心口诀：据点要驻防，ranger 不填死亡格；预警一响先收人，radius 剩 3 就把钱换成兵；打集火先断通道，调 API 先核邻格。**
> **一句话总结：我用三轮抢点把经济打到 44:36 的峰值，却把一个不设防的据点（supply_northwest）连本带利输给了对手的 ranger 通道——两个 ranger 死在同一个暴露格、唯一 heavy 在四单位交集中空血阵亡、R10 预警后两个单位白吃 50 点炮火、141 补给在 ring 吃掉全部据点后烂在仓库——终局 3 个残兵对 6 个单位，军力 30:222、总分 640:1184，把一场经济开局打成了同图三局里最惨的完败。**
