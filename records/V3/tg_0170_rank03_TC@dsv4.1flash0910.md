## 失误与改进

非第一名，逐条写「实际做法 vs 正确做法、触发条件、预期收益」：

1. **实际做法**：R1–R5 我把全部 4 个初始单位 + 5 次部署投向离家最近的西南/南部环带，把中央口袋视为不可达。
 **正确做法**：从 R1 起就该派 1 个侦察兵（移动力 5）沿外圈直插 (-4,-3)/port_4，抢在 c 完成拆障（R1/R4/R5 三次 demolish）之前占住 gateway，或用重型与我方步兵在 (-2,-2) 卡位。
 **触发条件**：地图 `whirlpool` 三个 HQ 同处中央口袋、`deployFromHq: false`、`port_4` 是口袋唯一入口，且我的出生位是 `slot_sw`（距门口最远）。
 **预期收益**：延迟 c 的隧道 2–3 轮 → HQ 少挨 60–90 伤害（300–450 分），并保住 `ownHqHp` 项；即使仍会输，也不会在 R12 就被清零。

2. **实际做法**：R9/R10 我把两个单位用于打 c 的堵口步兵 2de5c8（22 + 25 伤），它被 `port_4` 的据点维修 +6 拉回，我差 8 点没能击杀。
 **正确做法**：同一目标要在**同一轮内**用两个单位同时出手（例如 09fb1d + a4e67b 同轮打 22+31 ≥ 64），而不是把 22 和 25 拆到两轮，给对方一次维修窗口。
 **触发条件**：敌方单位站在 `forward_base`（`repairAmount: 6`）或 `repair` 据点上。
 **预期收益**：直接击杀 + `unitsDestroyed`、减少 c 的军力价值，并把 (-3,-3) 走廊打开一格；R10 那一轮我实际有 4 AP 和 2 个可攻击单位。

3. **实际做法**：R5/R9/R12 我把 AP 大量投入「造价最低的侦察兵」刷部署 merit（全场 10 个侦察兵），R12 一次拍 3 个。
 **正确做法**：在 HQ 只剩 3 HP、必被淘汰的终局，应优先把补给换成 `armyValue`（重型 100 补给 = 140 HP×108 成本，折算军力价值远高于 3 个侦察兵），并把 AP 用在能造成 actual 伤害的攻击上（每次 20+ 伤害 = 2 merit，与一次部署同分）。
 **触发条件**：`supplies` 权重为 0、`armyValue` 权重 0.5、`effectiveActions` 为 4。

## 与历史对局对比

1. **`records/V3/tg_0149_20260917.json`**（multiplayer-ring / standard / 2 人，`Dsv4.1Flash0910-OMP` 胜，`turn_limit_score`）：同为环形图标准模式，同族模型赢在**据点经济与行动点效率**。本局是该经验的**修正**：环形图的中心在 `multiplayer-ring` 上可以通过多条支路争夺，而 `whirlpool` 的中心是一个**单格走廊口袋**——同样的「外圈铺据点」打法在这里被 HQ 直射位直接击穿，说明**在收缩型地图上，HQ 通道优先级必须高于据点扩张**，这是对旧经验适用边界的修正。

3. 新发现（本局首次出现的地图）：`whirlpool` 是档案中**第一局** whirlpool 对局。它给出一个可复用的判据：若某张图上某方 HQ 的相邻可站平地 ≤ 2 格、且其中一格与对手出生区连通，则该图的标准模式会退化为「谁先占住那格谁赢」，此时 `armyValue 0.5` 与 `controlPoint 50` 的杠杆全部失效。

## 总结

### 做得好的

1. **经济与 merit 抽取效率高**：12 轮内 7 次占领、15 次部署、14 次攻击，`actionMerit 50`、`actionScore 200`，在 3 人中排名第二（`actionScore` b 264 / 我 200 / c 232，对应 merit 66/50/58）；且补给用到只剩 4（`supplies` 权重 0，等于没有浪费）。
2. **在必败局面下没有放弃增值**：R9 用侦察兵与步兵配合拿到 2 个击杀（seq 205/207），R11/R12 仍把 c 的步兵 6ee608 打到剩 13 HP——该单位最终由 b 在 R16 补刀。
3. **全程未出现被拒动作**：15 次部署与 14 次攻击全部 `ok`，没有因坐标/射程/补给错误浪费 AP。

### 下次改进

1. **开局先判「HQ 炮位」**：读图时先算出**每个 HQ 的相邻可站平地数量**。触发条件：该数 ≤ 2 且与对手出生区同侧 → 立刻派移动力 5 的侦察兵去占/堵那个格子，放弃该侧据点扩张。预期收益：避免本局 R6–R12 那种每轮 −32、无法还手的失血。
2. **同一目标同轮集火**：触发条件：目标站在 `forward_base`/`repair` 据点（有 `repairAmount`）上 → 用 ≥2 个单位在**同一轮**打同一目标，单轮伤害必须 ≥ 目标剩余 HP + `repairAmount`。预期收益：本局 R9/R10 本可击杀 2de5c8，少养 c 一个堵口单位。
3. **终局把补给转成军力而非数量**：触发条件：`supplies` 权重为 0 且 HQ 无法保住 → 优先部署造价最高的可用单位（重型 108）以最大化 `round(cost × hp/maxHp)`，并把 AP 优先给「能打出 20+ actual 伤害」的攻击（2 merit/AP 与部署同分，但还削对手军力）。
