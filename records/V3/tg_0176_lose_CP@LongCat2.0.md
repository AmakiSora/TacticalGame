## 核心教训与关键转折

**转折一（R1-R3，战略重心失守）：开局抢占补给的速度落后。**
我 R1 抢到 supply_east，R2 再拿 supply_northeast，手上 2 个补给点。但对手在 R2 一下子就抢到 3 个补给点（supply_west、supply_northwest、supply_southwest），加上出生地 cp_west = 4 个点。这导致对手从 R3 起就有 36/轮收入，而我只有 28/轮。整个经济差距从此拉开，到结束时对手比我多收入 68 补给，直接决定了部署数量对等但质量不同的战局。

**转折二（R4-R8，交换比灾难）：4 步兵换 1 步兵 + 1  infantry。**
这是我输掉本局的直接原因。R4 到 R8 连续苦战中，我方 infantry `af87d8d6`(seq75) 和 `b9ad2585`(seq108) 相继阵亡在 (2,-1)/(2,-2) 接触线上，而对手只损失了 1 个 infantry (`51e8911b` seq114)。集火排序出了问题——我在前线反复用步兵贴脸对拼，没有严格执行"可击杀优先"，每次都让残血步兵继续送死。正确做法：一单位血量进入对手"−3 最高伤害"击杀线就应该后撤或换下，而不是让它再吃一发白白送掉。

**转折三（R9，scout 部署在危险线上）：scout 部署位失误。**
R9 我在 seq134 把 scout 部署在 (3,1)——这是 cdist=4 的格子，恰好在 safeRadius=3 的危险线上。它一上场就被炮击 −25HP（65→40），等于白亏一个部署单位的健康值。正确做法：部署目标格的 cdist 必须 < safeRadius（即 cdist≤2 当 safeRadius=3 时），或者确保下一步就能挪入安全环。

**转折四（R10，对手卡死 + 时间损失）：对手代理崩溃 4+ 小时。**
这段中断打乱了我的战术节奏。恢复后对手的布防和前期完全不同，导致我的 R11/R12 计划需要大幅调整，直接导致最后两个 infantry 在调整期被围攻致死。这属于非战术因素，但提醒我：在线对战时必须考虑对手恢复后的状态差异。

## 实际做法 vs 正确做法

1. **❌❌ 前线步兵反复送死，未执行"可击杀→高价值→占点"排序。** 触发条件：前线对拼时凭直觉而不是"谁来补最后一刀"选择目标。结果：3 个 infantry（135 cost）换来对方只有 1 个 infantry（45 cost），净亏 90 cost = 约 45 裁决分。**正确做法：每行动前重新扫描所有敌方单位的当前 HP，若任一敌方单位进入我方某单位的"最高伤害≥HP"触发集火条件，优先把集火填满到击杀线，再转火下一目标；残血单位不主动进入对手攻击范围。**

2. **❌ scout 部署在 cdist=4 危险线上。** 触发条件：R9 部署 scout 前未计算目标格 (3,1) 的 cdist。结果：上场即被炮击 −25HP（相当于白亏半个人头的血量）。**正确做法：部署前计算 `dist = max(|q|, |r|, |q+r|)`，确认 dist < safeRadius 再把单位放出去。**

3. **❌ 中期（R5-R8）经济落后却未调整兵种结构。** 触发条件：明明看到对手经济领先（36 vs 28），仍然把每轮补给花光在 infantry(45) 上，从没为 ranger(72) 攒过钱。结果：被对手隔着安全区的远程火力主导了 R9 之后的交战。**正确做法：R5 起就应该规划一条"R7 出 ranger"的资金线（攒 2 轮不部署），用 3 格射程对抗对手的 3 格射程。**

4. **❌ R1 起始部署全用 infantry。** 触发条件：初始经济 45（刚好 1×infantry）+ cp_east 只能出 infantry（92 heavy 当时买不起）。结果：初始兵种单一，前线缺乏抗线/火力差异化。**正确做法：出生经济 45 = 1 个 infantry，这是出生经济限制没办法；但 R2 起 32 补给就应该为后续 heavy/ranger 留弹药，而不是全铺 infantry。**
