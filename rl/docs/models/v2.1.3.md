## 训练过程与超参数（**本模型的独特之处**）

zip 内 `data` 显示 v2.1.3 用了一套**与前后各版都不同**的超参，是 v2.1 系列里唯一一次明显的调参实验：

| 超参 | v2.1.3 | 对比：v2.1.1 / v2.1.4–v2.1.8 的标准配置 |
|---|---|---|
| `learning_rate` | **1e-4** | 3e-4 |
| `gamma` | **0.995**（更长视野） | 0.99 |
| `ent_coef` | **0.003**（更低探索） | 0.01 |
| `n_steps` | **512**（更大 rollout） | 256 |
| `batch_size` | **128** | 64 |
| `clip_range` | 0.2 | 0.2 |
| `n_epochs` | 10 | 10 |
| `target_kl` | None | None |
| 设备 | GPU（2.11.0+cu128） | GPU |

`num_timesteps=800,256`、从零训练、`_n_updates=15,630`。这套「低学习率 + 高 gamma + 低熵 + 大缓冲」的保守配置，配合 800k 步与单一 defensive 对手，是它在作废批次里反而更稳的可能原因之一（但见下：训练环境本身仍有缺陷，超参不是决定因素）。

奖励常数与 v2.0.0/v2.1.1 逐位一致（见 `env_v22._shaped_reward`）。

## 已知环境缺陷与对手特性

- v2.1.3 同样训练于「**移动只走一格 + 奖励立即结算无占点信号**」的 v2.1 环境（分别由 v2.1.6、v2.1.7 修复），棋力上限有限。
- **单一 defensive 对手**：`env_v22` 中 defensive 风格优先级为 `攻击 → 治疗 → 补给≥70 部署 → 移动`。对单一脚本训练，**过拟合风险高**；与 modelmix 系列（v2.1.4+，对手含 v2.0.0 模型）横向对比时须注意训练条件不同（`RELEASE_NOTES` v2.1.7 专门补了这条说明）。

## 性能记录

评估协议：`evaluate_cross.py`，确定性策略，`default` 地图，15 回合裁决。

- **强于作废批次**：互打中稳定强于 v2.1.4–v2.1.8（对比 **8:0 / 14:0**）。
- **弱于 v2.0.0**：两种座位均 **0:4 以上**。
- `ep_info_buffer` 收尾 100 局平均回报 **30.57**（区间 22.01–31.36）、平均局长 109.3 步（97–112）——回报高于 v2.1.1（24.24），但对手是较被动的 defensive 脚本，且回报量纲受塑形项影响，不能直接换算成棋力。

## 部署与兼容性

- 54 动作 / 3922 维由 `run_model_v22.py` + `env_v22.py` 承载；`bots.ts` 按文件名版本分流到 v22 运行器。
- 因单一对手 + 环境缺陷，不作任何场景推荐；保留价值是作为 v2.1.4–v2.1.8 作废判定的对照标尺。
