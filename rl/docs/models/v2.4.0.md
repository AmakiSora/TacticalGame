## 网络、观察和动作

- **网络（本代核心变更）**：`RL_NET_WIDTH=256` 参数化策略/价值网络宽度（此前固定 64），即两个 `5974 → 256 → 256` 的 Tanh MLP（`policy_kwargs={'net_arch': {'pi': [256,256], 'vf': [256,256]}}`），动作头 54，参数量 3,204,919。动机：5974 维观测压进 64 宽是**最大信息瓶颈**。
- **观察/动作**：观测仍 5974 维相对视角（同 v2.3.x，详见 v2.3.1 档案）；动作 `Discrete(54)` 语义不变。观测/动作/奖励语义与 v2.3.x 完全一致，**仅网络容量变化**。
- **兼容性**：仅对从零训练生效；续训以模型内保存的 `policy_kwargs` 为准（sb3 加载校验，架构不一致直接报错），因此 **256 网络与 64 网络断点互不兼容**。

## 训练过程与超参数

- 4 环境并行、GPU；**大缓冲配套**：`n_steps=512`、`batch_size=256`（并行下每轮回调 2048 帧）；快照频率调密（`RL_SNAPSHOT_FREQ=10` 次回调 ≈ 每 2 万帧）；评估 40 局/次；学习率 3e-4→3e-5 线性衰减（交付 zip 已清洗为常数，续训重新注入）；锚点对手 v2.3.3。`clip_range=0.2`、`ent_coef=0.01`、`gamma=0.99`、`target_kl=None`；`_n_updates=9570`。
- **代码页崩溃插曲**（`6ef0bd8`）：首次启动约 3 分钟处因中文 Windows 代码页 936 传染、GBK 输出被 `local_env.py` 按 UTF-8 解码而整链崩溃（`UnicodeDecodeError`）。修复：worker 管道解码加 `errors="replace"` 容错 + 启动器固化 `chcp 65001` + `PYTHONUTF8=1`。重跑后 200 万步完整跑完。
- **收敛更慢、峰值在后期**：交付 best 在 196 万步（`num_timesteps=1960000`），与前三代 best 偏早期不同——大网络收敛更慢。

## 性能记录

评估协议：确定性策略，双座位换边。

| 对局 | 结果 |
|---|---|
| vs mixed 规则对手（随机图，20 局） | 14:0:6，平均据点 **2.20**（历代最高） |
| vs `v2.3.3`（随机图，8 局换边） | **5:3** |
| vs `v2.2.0`（随机图，8 局换边） | 5:3 |
| vs `v2.2.0`（**default 验证集**，8 局换边） | 6:2 |
| 训练期评估（随机图、规则对手，40 局，200 点） | 区间 32.5%-77.5%，综合 best@196 万步 |
| `ep_info_buffer`（收尾 100 局） | 平均回报 14.15（区间 −10.61–46.39），平均局长 118.5 步（39–259） |

- **代际互打保持优势（每代 5:3），但优势幅度没有随网络容量拉大**；对 v2.2.0 的比分（6:2 / 5:3）略低于 v2.3.3 时期（7:1 / 7:1），8 局样本下差距在噪声范围内。据此判断：**64→256 的容量升级边际收益已接近饱和**，棋力上限更可能受限于**对手生态**（规则对手 + 自身快照）与**观测表达**，而非网络容量——这一判断直接指向 v2.5.0（扩观测）与 v2.6.0（生态加压）两条实验路线。
- **对规则胜率持平但据点数持续上升（1.70→1.95→2.20）**：控制地图的能力在稳步变强。
- ⚠️ **样本口径提醒**：8 局换边成绩早于 `--swap-sides` 座位 bug 修复；default 拆座位复测显示 v2.4.0 坐 player_a 对 v2.2.0 为 **0:8**、后手才能赢（后手 4:4/7:1），16 局复测仅 9:7——历史 6:2 属换边小样本噪声。

## 部署与兼容性

- **双座位可战**，任意标准双人地图当时推荐都用本模型（服务器当时仍是 v2.3.3，可部署替换）。
- 256 网络与 64 网络断点互不兼容；可在当前环境续训（断点 `rl/checkpoints/random/20260830-015922/` 至 200 万步）。
- 作为 v2.5.0/v2.6.0 的**自对弈锚点**长期出场；直到 v2.7.0（6205 维可观测性修复 + 混合地图 + 配对评估）在随机图 96 局以 **66:30**（95% Wilson 下界 58.9%）确认超越，才交出 champion 位。
- 3922 维旧模型不能加载进本环境；跨版本对战用 `evaluate_cross.py`（5974→env_v24）。

## 一句话总结

v2.4.0 把网络从 64 扩到 256（参数量 77.7 万→320 万），据点控制力创新高（2.20），并长期担任 champion 与后续多代的自对弈锚点；但代际互打幅度仍是 5:3，说明容量升级边际收益已近饱和——瓶颈转向对手生态与观测表达，为 v2.5/v2.6 两条（最终都被证伪的）实验和 v2.7 的可观测性修复埋下伏笔。
