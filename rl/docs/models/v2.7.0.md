## 网络、观察和动作

- **网络**：`6205 → 256 → 256` Tanh MLP ×2（`net_arch={'pi':[256,256],'vf':[256,256]}`），动作头 54，参数量 3,323,191。
- **观察 `Box(-1,1,(6205,))`** —— 本代核心「可观测性修复」，权威构成（`env_v27._encode_state`）：

  | 段 | 维度 | 内容 |
  |---|---|---|
  | 棋盘格 | 331×18 = 5958 | 半径 10 标准定序，每格 18 维（地形 3 / 据点归属 3 / 单位或总部归属 3 / 兵种 5 / HP 比 1 / hasMoved / hasActed / 槽17 攻击力`/60`或总部防御`/15`），同 v2.3/v2.4 |
  | 全局 | 16（写前 12） | 补给、总部 HP、回合数、已用 AP、据点占比、单位数、半径、不可通行占比（动态归一化），同 v2.3/v2.4 |
  | **12 稳定单位槽** | 12×15 = **180**（新增） | 每槽：占用位 1 + 兵种 one-hot 5 + `q/10` + `r/10` + HP 比 + hasMoved + hasActed + actionSpent + `attack/60` + `moveRange/8` + `attackRange/6` |
  | **规则参数** | **51**（新增） | 5 兵种 × 8（`hp/200`、`attack/60`、`defense/20`、`moveRange/8`、`attackRange/6`、`cost/150`、`healPower/60`、`canCapture`）+ 11 全局（`startingSupplies/150`、`baseIncome/30`、`controlPointIncome/30`、`damageVarianceRange/10`、`healVarianceRange/15`、总部 `defense/20`，以及裁决权重 `enemyHqDamage`/`ownHqHp`/`controlPoint`/`armyValue`/`supplies` 各 `/100`） |

  合计 `5958 + 16 + 180 + 51 = 6205`。**解决两个长期问题**：① 动作索引与棋子身份脱钩——12 稳定单位槽让「动作槽 ↔ 具体单位」在观测里显式对应；② 随机规则不可见——每局随机的兵种数值/经济/裁决权重现在直接进观测。
- **动作**：`Discrete(54)` 语义不变（`end_turn` + 12 稳定槽 × 4 意图 + 5 部署槽）。

## 训练过程与超参数

- 超参（zip `data`）：`n_steps=512`、`batch_size=256`、lr 3e-4→3e-5 线性衰减（交付 zip 清洗为常数）、`clip_range=0.2`、`ent_coef=0.01`、`gamma=0.99`、**`target_kl=None`**（target_kl 是 v2.8 才引入）；GPU；`_n_updates=19280`。4 环境并行。
- **配对评估**：训练评估**固定种子、强制双座位配对**，按最弱场景优先选 best；同时评估随机规则、随机 champion、default champion 三场景；评估每 5 万帧、每场景 20 局。
- **混合地图训练**：随机图默认混入 default/dual-lanes/forge，**降低静态地图灾难性遗忘**（针对 v2.6.0 的 default 0:24）。
- **自对弈采样**：默认自对弈 70%，锚点（v2.4.0）出场率 40%；历史快照扩到 16 个并**均匀采样**，避免近期快照共同适应导致策略漂移。

## 性能记录

评估协议：确定性策略，随机图 96 局、48 个全新种子**成对换座**对 v2.4.0（大样本 + 分座位 + Wilson 下界，是本代确立的严格验收协议）。

| 对局 | 结果 |
|---|---|
| vs v2.4.0，随机图，96 局成对换座 | **66:30（68.8%）**；95% Wilson CI **58.9%–77.1%** |
| 随机图分座位 | player_a **35:13**（下界 59.0%）；player_b **31:17**（下界 50.4%） |
| vs v2.4.0，default，24 局换座 | **24:0**（两座位均 12:0） |
| vs v2.4.0，forge，24 局换座 | **19:5** |
| vs v2.4.0，dual-lanes，24 局换座 | **14:10**（player_a 3:9、player_b 11:1，明显座位效应） |
| 训练期交付点（395 万帧） | 三场景最弱胜率 85%，平均胜率 95%，平均据点 2.57 |
| `ep_info_buffer`（收尾 100 局） | 平均回报 16.19（区间 −7.52–46.62），平均局长 110.4 步（44–200） |

- **随机图大样本 + 两个座位下界均达预设晋级条件**，default 灾难性遗忘也已消除（24:0）——这是它取代 v2.4.0 成为 champion 的硬证据。
- **dual-lanes 座位效应**：总比分没退化，但两代模型都呈现显著座位效应（player_a 3:9、player_b 11:1）；该问题**不能靠继续训练当前 54 动作空间可靠解决**，应在下一代「可选移动落点/目标动作空间」中重点验收——这是 v3.0 分层动作空间的直接动机之一。

## 一句话总结
