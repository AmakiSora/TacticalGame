## 网络、观察和动作

同 v3.0.0-v3.0.2（详见 v3.0.0 档案）：`hex_transformer` 棋盘编码器（`d_model=64/n_heads=4/n_layers=1/features_dim=512`，actor/critic 共享，`net_arch pi[256]/vf[256]`），观测 6715 维（前 6205 同 v2.7 + 尾部 510 维候选描述），动作 `Discrete(155)`。

## 起因：round_robin 全图评分与 champion 头衔脱节

2026-09-07 全量 round_robin（15288 局 Bradley-Terry）显示 **v3.0.2-1.4M 总榜仅第 6（1563）**：random 图第 1（77%），但 **danger-close 全场垫底（28%、先手座 8%）**，对 v2.1.3/v2.3.3/v2.5.0/v2.6.0 全部 0:24；全图最强反而是蒸馏+5 万步 PPO 的 v3.0.0（1661）。用每局明细（`rl/leaderboard/details/`）定位败因：

- **部署饥饿**：v3.0.2 在 danger-close 负局平均部署费 81（约 1 个步兵），胜局 284；败法为 11-15 回合被歼灭，或 30 回合裁决分被更厚部队反超（该图 1 行动/回合、HQ 120 血、裁决重 HQ 伤害权重 20 与军队价值）；
- **根因**：`RL_TRAIN_MAP_MIX` 只含 random:0.7 + default/dual-lanes/forge——**breach / danger-close / desert 从未进过训练分布**，且 PPO 在 random 为主的分布上越训越偏（danger-close：v3.0.0 46% → v3.0.2 28%）；
- **锚点天花板**：v2.7.0 固定 40% 出场且不参与 PFSP，而它早已被打穿（v3.0.2 验收 64% 胜它）。

## 配方改动与管线修复

1. **best 选择键拆分**（`eval_worker.selection_score`）：评估结果每场景新增 `map` 字段，选择键改为 **(分布内最弱场景下界, 分布内后手座合并下界, 分布内平均下界, 占点, 回报)**——分布外静态图场景照常写 TB（新增 `eval/ood_min_wilson_lb`）与日志（`ood_lb=`），**不参与 best 选择**。v3.0.2 的 `min_wilson_lb` 曾被 default OOD 崩塌主导选错断点。旧结果 JSON（场景无 `map` 字段）向后兼容按分布内处理。新增 `tests/rl/test_v303_selection.py` 5 例（`npm run test:rl` 28 项通过）。
2. **地图混合补全**：`RL_TRAIN_MAP_MIX=random:0.5,breach:0.083,danger-close:0.083,default:0.083,desert:0.083,dual-lanes:0.083,forge:0.083`（`local_env` 按权重归一化逐局抽取）。
3. **锚点换血**：v2.7.0 → **v3.0.0**（与 v3.0.2 同 155 动作空间，无需 54 动作映射），`RL_ANCHOR_PROB=0.20`。
4. **断点加密**：`RL_SAVE_FREQ` 20000→10000 次调用（8 环境 = 每 8 万帧一存）。

## 训练过程与探索

- **配方**：v3.0.2 1.44M 断点直接续训（**不再蒸馏**——「蒸馏+少量 PPO 到顶」是探索死锁未修复时的结论；注意 sb3 resume 语义 `RL_TIMESTEPS` 为**新增**帧数）。8 环境、lr 5e-5→1e-5 线性衰减（resume 按本次进度起点约 3.9e-5）、`ent_coef=0.03`、`target_kl=0.02`、评估 10 万步 × 96 局。
- 超参（zip `data`）：`n_steps=512`、`batch_size=256`、`clip_range=0.2`、`gamma=0.99`、`ent_coef=0.03`、`learning_rate` 交付清洗为常数 5e-5、`num_timesteps=5000000`。
- **全程健康**：`explore/new_candidate_rate` 稳定 1.2%-1.5%（attack 新候选峰值 10.5%），`explained_variance` 0.76-0.82，target_kl 未触发，无 GPU 中断。
- **评估单调走强**：分布内最弱下界从早期 15-26% 爬到 4.8M 的 45%、5.0M 的 **50%（全程 best，即交付断点）**；`default_champion` 场景（对 v3.0.0）从早期 8-21% 修复到 **75%（下界 65%）**——地图混合补全直接兑现。

## 一句话总结

v3.0.3 用 round_robin 榜单与每局明细数据定位出 v3.0.2 的偏科根因（三张静态图不在训练分布 + 锚点被打穿仍固定 40% 出场 + best 选择键被 OOD 崩塌主导），以「全 7 图混合 + 锚点换 v3.0.0 + 选择键拆分」的纯配方改动从 1.44M 断点续训 356 万帧，交付 5.0M 断点：对上代 champion 480 局 **73.3%（下界 69.2%）**，把 danger-close 从全场垫底（28%）修到 **96:0**，成为新全地图 champion，并把 breach/desert 的退化与 default 先手座留作下一版观察项。
