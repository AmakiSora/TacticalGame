## 二、失败不是座位锁：default 是技巧决定型地图

全胜，说明模型本身没坏、只是打不过强模型对手。

## 三、病根：「步兵海」在长训后复发

| 造成伤害 | 774 | **1111** |

**这就是 v3.2.0 用 A5 novelty 奖励修过的老毛病（当年 85% 步兵），在 14M 帧长训后复发。**
A5 只奖励「每兵种**首次**部署」——收完就没了，对长跑无效。步兵海在随机图上尚可混，
进静态图即被游侠火力压制（v3.1.1 游侠占比 47%）。

对照：v4.0.0 在唯一大胜的 danger-close 上，游侠占比 **62%**（它最擅长的图恰是远程火力图）。

## 四、本代的两条硬结论

### 结论 1：「对算法 16.5%」是测量假象

| 协议 | v3.1.1 对算法 |
|---|---|
| `eval_worker`（随机图） | threat 41% / greedy 45% / field 64% |
| `arena`（全 7 图聚合，`arena/matches.jsonl` 1008 局） | threat 28% / field 22% / **总计 40%** |

分图拆解（arena）：random 54%、default 49%、dual-lanes 44%、danger-close 42%、
forge 41%、breach 33%、**desert 17%**。

⇒ 算法对手在静态图上被压制得最狠，而 arena 把 7 张图平均起来，于是「静态图弱」
被读成了「算法强」。**v4.0.0 花 20M 帧练算法对抗，练的是一个在训练分布上几乎
不存在的缺口。**

### 结论 2：「从零 + 大容量」不解决静态图问题

- 容量：0.87M → **1.44M** 参数（`2 层×d128` + `net_width 512`），吞吐 240–260 fps（8 环境）
- 从零：蒸馏冷启动（算法教师 400 局 / 27.5k 样本 / fallback 3.4%）→ 14M 帧
- 结果：静态图三张 **0%**，与 v3.1.0/v3.1.1 的 whack-a-mole 同型

⇒ 静态图训练权重 **0.05 地板**根本守不住——**不是容量问题，是分布覆盖问题**。
这与 v3.1.1 的诊断一致（whack-a-mole 根因 = 随机域太窄），但本代进一步证明：
「随机域拓宽」到不了静态图所在的生态位（联合边角命中率仍是乘积级）。

## 五、S3 消融：对手配比 + 抬 LR = 确定性退化

S3（算法 30%→40%、自对弈 70%→60%、lr 8e-05→2e-05）同步骤对照（累计步相同）：

| 累计步 | S2 配方 rule/thr/grd/fld | S3 配方 rule/thr/grd/fld |
|---|---|---|
| 11.6M | 73 / 39 / 45 / 53 | 70 / 42 / 41 / 53 ← **几乎相同**（S3 刚起步） |
| 12.4M | 70 / 36 / 41 / 49 | 68 / 30 / 32 / 44 |
| 13.2M | 72 / 44 / 45 / 58 | 69 / 34 / 36 / 48 |
| **14.0–14.2M** | **72 / 41 / 49 / 59** | **64 / 33 / 30 / 39** |

11.6M 处两条轨迹重合，之后**分叉并单调拉开**——教科书式的因果归因。机理：
`explained_variance` 从 0.64 掉到 **0.46**、`ep_rew_mean` 从 5.5–6.9 掉到 4.83。

**这是第四次复现「收敛后继续训练 = 退化」**（v3.2.0 champ5、r3x，现在 S3）。
S3 名义上是「结构性阶段」，但改的东西（对手配比 + LR）**本质还是配方**，
于是又撞上 v3.2.0 结项时那堵墙。

**副产品**：新增的 `RL_EVAL_ALGO_IN_SELECTION` 开关（算法场景进 best 选择键）
第一次上场即正确发挥作用——best 停在 S3 起点（11.6M），此后 14 个评估点无一超越。
若无此开关，S3 的 13.8M（rule 76%、lb 67%）会被 rule-only 选择键选为 best，
那才是真正的错误交付。

## 七、下一步方向（已由本代数据修正）

**不要再打算法。** 下一轮的唯一目标是**静态图**：

1. **提高静态图训练权重**（0.05 → 0.12–0.15）。此前担心 whack-a-mole，但本代证明
   0.05 的地板权重连「不崩」都做不到，而 v3.0.4 的「削权重→整图遗忘」是**削**的教训，
   不是**加**的教训。
2. **修步兵海**：A5 从「首次部署一次性奖励」改成**持续性的兵种多样性奖励**
   （或直接给游侠使用率加塑形项）。这是跨代复发的病根，值得单独一轮消融。
3. **起点用 S2 的 11.4M 断点**（容量已验证、算法对抗已达标），**不再从零**——
   从零的收益（容量 0.87M→1.44M）已被证明不是瓶颈。
4. 算法占比回落到 **20%**（v3.2.0 验证过的有效暴露量），自对弈回到 70%。
